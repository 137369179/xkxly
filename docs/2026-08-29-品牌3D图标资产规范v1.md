## 一、视觉规范（统一风格）

| 维度 | 规格 |
|---|---|
| 形态 | **3D 黏土 / 果冻质感**，Q 弹圆润，柔和高光，软阴影 |
| 构图 | **居中居中**，主体饱满占画面 60-70%，留白 30-40% |
| 背景 | **奶白纯色**（新设计系统 v1 `--color-bg` 概念） |
| 调色 | 套用设计系统 v1 六色板：每图锁定一个主色（pink/blue/yellow/green/purple/orange） |
| 文字 | **不含任何文字 / 字母 / 数字 / 水印**（除生成侧的水印需后期去除） |
| 边框 | 无边框 |
| 风格关键词 | 3D、黏土、果冻、Q 弹、儿童、可爱、糖果、对标宝宝巴士/洪恩识字 |
| 比例 | 1:1 正方形，**原始 1024×1024 → 交付 256×256 WebP**（实际渲染 36-64px，256 已覆盖 3× 视网膜屏） |

> ⚠️ **性能治理已落地**（2026-08-29 收口）：41 张 1024² PNG 原计 47MB，经 `cwebp -q 82 -resize 256 256` 转 WebP 后 **0.24MB（降 99.5%）**，原始 PNG 已删除，代码中引用统一为 `.webp`。WebP 被所有现代浏览器（含 Safari 14+）原生支持，无需代码改动。

## 四、批量生产 Prompt 模板（可直接复用）

```
3D 黏土质感儿童教育品牌图标：{具体物体/动作描述}，
Q 弹圆润、果冻高光、柔和的软阴影，
{主色名}主色调，居中构图，奶白色纯背景，
无文字，无边框，卡通可爱，高级质感，
对标宝宝巴士/洪恩识字图标风格
```

- `具体物体`：与原 emoji 语义对应（如「一个会写汉字的小熊猫（代表汉字）」「一辆糖果消防车（代表安全）」）
- `主色名`：pink / blue / yellow / green / purple / orange，与 `tones.ts` 的 `Tone` 取值一一对应

## 六、已知限制与治理

1. **ImageGen 水印**（右下"AI生成 WORKBUDDY"）：付费层或后处理去除；规模上去后建议一次性批量去除脚本
2. **图标局部语义偏差**：图像生成对 prompt 解读有随机性，首批 8 个已人工确认符合岛屿/底栏语义；后续每批建议**人工目检 1-2 个**再发布
3. **国际化无文字**：当前规范强调"无文字"，但若未来需支持多语言单图标（如标志/装饰），需额外变量化
4. **暗色模式**：当前仅浅色背景，深色模式需重新生成（暗色果冻质感）
5. **性能**：✅ **已治理**——见第一节注。41 张 1024² PNG（47MB）→ 256² WebP（0.24MB，降 99.5%），原始 PNG 删除，代码引用统一 `.webp`；`vite.config.ts` 当前 `emptyOutDir: false`（CI 安全考量，见其 TODO），故切换后需手动清理 dist 陈旧 PNG（已清理）。后续若增删图标资产，注意手动清 dist 或恢复 `emptyOutDir: true`

## 七、与品牌资产生产 Skill 对接

- **3D 黏土图像** → 当前用 `ImageGen` 工具（一次 5-10 积分）
- **3D 真模型**（.glb） → 加载 `3D模型与视频特效` 技能 `buddy-cloud.py 3d` 命令，适合 IP 形象（如吉祥物/小茜机器人）的 3D 模型导入应用
- **页面级可视化编辑** → `设计模式` 技能（页面可视化编辑器），用于把新图标视觉化应用到原型 HTML
