## 三、具体实施内容（6 文件 + 测试追加）

### 3.1 `praise.ts` 新增 idiom 场景（成语专属语料）

- `PraiseScene` / `EncourageScene` 增加 `'idiom'`；
- 表扬语 5 条：「成语接龙接得妙！」「这个成语用得准！」「成语记得真牢！」「成语含义理解得对！」「接龙接得太棒了！」；
- 鼓励语 4 条：「成语再想一想」「看看字义再试试」「这个成语再认认」「换个成语接一接」；
- `skillToPraiseScene` 映射 `idiom:xxx` / `idiom-chain` → `'idiom'`。

### 3.2 成语 `IdiomChain.tsx`（游戏化接入）

- 新增 `streak` 连对状态 + `<StreakBar target={3} tone="purple">` 闯关里程碑（计分区下方）；
- 答对：`streak+1`，3 连对走 `answerCorrect('combo')` 连击表扬，否则 `answerCorrect('idiom')` 成语场景表扬；
- 答错/跳过：`streak=0` + `answerWrong('idiom')` 温和引导；
- 开局重置 streak。

### 3.3 拼音 `TonePractice.tsx` + `BlendPractice.tsx`

- 各新增 `streak` 状态 + StreakBar（TonePractice `tone="yellow"` 因 orange 非 StreakBar 支持色映射暖色；BlendPractice `tone="blue"`）；
- 答对 3 连对走 `answerCorrect('combo')`，否则 `answerCorrect('pinyin')`；答错 `answerWrong('pinyin')` + 归零；
- 保留既有 combo 徽章 / Haptic 震动（不重复造轮子）。

### 3.4 古诗 `PoemTrain.tsx`

- `pick` 作答处接入统一反馈：答对 `answerCorrect('poem')`、答错 `answerWrong('poem')`（此前仅 sfxTap）。

### 3.5 测试补充

- `praise.test.ts`：idiom 语料贴合断言 + `idiom:xxx → idiom` 映射断言（+2 例）；
- `pinyin.test.tsx`：TonePractice / BlendPractice 闯关条渲染冒烟（+2 例）。
