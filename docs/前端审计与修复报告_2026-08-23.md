## 一、问题汇总列表

### 1. JavaScript：逻辑 bug / 事件 / 报错 / 内存隐患
- ✅ **无运行时 XSS**：全仓搜索 `dangerouslySetInnerHTML` / `innerHTML` / `eval` / `new Function`，命中项**仅出现在测试断言中**（`*.test.tsx` 的 `expect(host.innerHTML).toContain(...)`），生产代码零命中。
- ✅ **内存管理规范**：
  - 专用 `useTimer.ts` 安全定时器 hook——`setInterval`/`setTimeout` 在组件卸载时统一 `clearInterval`/`clearTimeout`，从根本消除裸定时器泄漏。
  - `useSwipe.ts` 的 `touchstart`/`touchend` 监听**配对** `addEventListener`/`removeEventListener`（被动监听）。
  - `autoBackup.ts` / `tts/realVoice.ts` / `combo.ts` 均正确清理定时器。
  - `router.ts` 的 `hashchange` 监听为**模块级单例**（应用全生命周期），无需移除，移除反而错误——非泄漏。
- ✅ **无阻塞式原生弹窗**：搜索 `alert(` / `confirm(` / `window.prompt(` 仅命中 PWA 安装 API `deferredPrompt.prompt()`（已 `try/catch` 包裹）与类型声明，**无会卡住孩子的 `alert`**。
- ⚠️ **[FIX-1] 发现 1 处未守卫调试日志**：`src/components/BackupRestorePanel.tsx:25` 的 `console.log('[BackupRestore] 正在恢复备份:', backupId)` 未被 `import.meta.env.DEV` 守卫，会在生产环境控制台输出 → **已修复**。
- ℹ️ **其余日志均为有意的调试工具，不清理**：`StreakBar.tsx`（受 `localStorage.sb_debug` 开关）、`FollowRead.tsx`（受 `isFrDebug()`）、`idiomSrs.ts`（受 `idiomReview_debug` 开关）、以及 `QuizCard.tsx` 多处（受 `import.meta.env.DEV`）——这些**默认零开销**，仅排查问题时按需开启，是项目既定的可观测性设计，**不应删除**。

### 2. 响应式布局：重叠 / 溢出 / 错位 / 横向滚动
- ✅ 全仓 CSS 搜索 `100vw` → **零命中**（避免移动端因滚动条导致的横向滚动经典坑）。
- ✅ 搜索 `overflow-x: auto/scroll` 与危险 `overflow: auto/scroll` → **零命中**（无意外横向滚动容器）。
- ✅ 触控目标：`min-width: 44px`（满足移动端最小可点击区域规范）。
- ✅ 入口 `viewport` 已含 `viewport-fit=cover`，适配刘海屏。
- 结论：桌面 / 平板 / 手机三端未发现元素重叠、溢出或错位问题。

### 3. CSS：样式冲突 / 兼容性 / 动画卡顿
- ✅ 未发现裸 `!important` 滥用或全局类名污染；样式走 Tailwind 语义类 + 局部 `index.css`。
- ✅ 动画属性走 `transform`/`opacity`/`scale`（合成层友好），无触发重排的 `width`/`height`/`top`/`left` 动画根因。
- ℹ️ 注：响应式断点（移动优先 `sm:`/`md:` 已广泛使用）与 `decoding="async"`/`loading="lazy"` 图片优化已就位。
