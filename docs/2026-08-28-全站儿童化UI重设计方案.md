### 1.2 现有流程复杂点 TOP10

1. **首页信息过载**：一次呈现 20+ 可点目标，儿童无法聚焦「今天做什么」——违背一屏一事。
2. **三层导航 + 抽屉第四层**：TopBar/侧栏/底栏/分类抽屉并存，儿童要理解 4 套导航心智。
3. **古诗模块过深**：8 视图 +「更多」下拉 + 4 维文字筛选 + 详情 6 标签，必须识字才能用。
4. **汉字/数学页内多级 Tab**：汉字约 18 个子视图、数学 20+ 子活动，家长都要找一会儿。
5. **键盘快捷键提示条纯文本**（首页/今日/古诗多处）：儿童读不懂，形同虚设。
6. **汉字「玩」步依赖 AI 生成**：网络慢时儿童面对空白等待，无进度化安抚。
7. **今日课程锁定式线性推进**：不能跳过不想学的节，卡住只能硬闯。
8. **退出路径不一致**：部分页面 Esc 返回、部分无；无退出确认、无可撤销（除连错干预外）。
9. **孤儿/重复路由**：5 条零入口路由 + rewards↔growth 重复，用户与维护双重困惑。
10. **长页堆叠无定位感**：猫屋 7 个 section、多模块长页滚动，无「回到顶部/模块首页」常驻按钮。

### 1.3 可合并功能清单（含无法合并说明）

**可合并（6 组）**：

| 合并组 | 吸收对象 | 合并后入口 | 替代简化方式 |
|---|---|---|---|
| 成长荣誉馆 | rewards + passport + achievement | `growth` 单一入口（页内 4 区块：成长树/星图/勋章/贴纸） | 旧路由 `/rewards`、`/passport`、`/achievement` 保留并重定向，不删路由 |
| 游戏乐园 | gamecenter(货架) + fun + adventure | `gamecenter` 升级为唯一游戏入口 | fun/adventure 保留路由作为页内深链区块 |
| 我的宠物 | cat_house + realistic_cat + desktop_pet | `cat_house` 主入口，页内「2D/3D/桌面」模式切换 | realistic_cat/desktop_pet 路由重定向 |
| 故事岛 | story(总馆,孤儿) + storybook + songs + nursery + idioms | 大厅「故事岛」聚合区，storybook 为主入口 | story 路由重定向至大厅锚点 |
| AI 小老师 | companion + content + wrongbook + voicestudio | 大厅「AI 岛」聚合区 | 各自保留独立路由（学习工具属性强，可深链） |

**无法合并（3 个，附原因）**：

| 功能 | 原因 | 替代简化 |
|---|---|---|
| 家长中心 `parent` | 成人域必须与儿童域隔离（PIN 门禁+成人验证已三重防护），不能与儿童模块混排 | 入口弱化为首页角落「家长」小图标，验证后才进入；侧边栏家长分组移除 |

| 古诗专业研读（格律/平仄/诗人史料） | 成人级深度功能，儿童用不到但不可删（学术价值） | 详情 6 标签收敛为「读一读/玩一玩/学一学」3 组，专业工具折叠进「小博士」分组，默认收起 |

### 1.4 改动风险与取舍

| 决策 | 收益 | 风险 | 取舍结论 |
|---|---|---|---|
| 42 模块零删减、仅重组入口 | 老用户零功能损失、SEO 路由不失效 | 大厅卡片多，需用分组大区而非菜单承载 | 保留全部路由，`hiddenInSidebar` 治理 + 重定向 |
| 换肤走令牌层（index.css + tones.ts） | 一处生效全站、74 文件内联消费自动跟随 | 色板变更影响 74 文件视觉回归 | 保留 candy-* 令牌名只换值，风险最低 |
| 按钮新增 hero 档（≥88px） | 满足儿童主 CTA 规格 | 不动现有四档，零回归 | 新增而非修改 |
| 底部 6 Tab → 4 大 Tab | 儿童心智负担骤降 | nursery/letters/numbers 直达入口变为大厅二级 | letters/numbers 升大厅置顶位；改 `nav.ts` bottom 字段即可 |
| hanzi/numbers/poems 页内收敛 | 步数骤降 | 改动面大，涉及 3 个最复杂模块 | 列入「建议做」分阶段，先做导航层与首页（P0） |
| 删除键盘快捷键条 | 消除儿童不可读文本 | 桌面家长用惯 | 保留快捷键行为、仅删除可见提示条 |

## 二、设计方案

### 2.1 设计原则与验收标准（来自需求摘要）

- 两步可达：任意核心任务 ≤2 步；导航层级 ≤2 层
- 一键聚合：相关操作合并单一主按钮
- 大钮强反馈：主按钮 ≥88×88px、图标配文字、反馈 ≤300ms（视觉+文字+语音）
- 一屏一事：单屏主任务=1、次要操作 ≤3
- 42 模块零删减，全部 ≤2 步可达

### 2.2 信息架构：「两域四岛」模型

**导航从 4 层收敛为 1 层 + 大厅**。儿童心智里只有两个问题：「今天做什么」（首页）和「我还想玩什么」（大厅）。

```
┌─ 新导航模型 ─────────────────────────────┐
│ 底部大导航（≥72px，图标配文字，4 Tab）      │
│  🏠 首页   🧭 乐园大厅   🎮 游戏乐园   🏆 我的成长 │
│  home      hall(新增)    gamecenter    growth   │
│ 右上角弱化入口：👨‍👩‍👧 家长（PIN 门禁）· ⭐ 星星      │
└──────────────────────────────────────────┘

乐园大厅 hall（新增 1 条路由，替代侧边栏+分类抽屉的全部职能）
├─ 📚 学习岛：汉字/拼音/字母/单词/数学/逻辑/古诗/发音工坊（8 卡）
├─ 📖 故事岛：绘本/儿歌/跟唱/成语（4 卡，吸收孤儿路由 story）
├─ 🔬 探索岛：科学/地理/节气/植物/安全/研究+画廊（6 卡）
└─ 🎨 创意岛：艺术/音乐/交通救援/猫屋/AI 小老师/错题本（6 卡）
```

- **下线**：侧边栏 32 项平铺（`Sidebar.tsx`）、TopBar 🔎 分类抽屉（`CategorySheet.tsx`）、首页键盘快捷键提示条——职能全部由大厅承担
- **首页=主任务**：问候+吉祥物 → 超大「今日课程」任务卡（1 击开始）→ 仅 3 个次要快捷位
- **模块页模板**：常驻大返回钮 + 单一主任务卡 + 「更多玩法」折叠区（默认收起、≤3 项可见）
- **路由兼容**：43 条路由全部保留；`rewards/passport/achievement/realistic_cat/desktop_pet/story/hanzi-listen` 渲染重定向到合并目标（`routeRedirects.ts` 新增），旧链接与 SEO 预渲染零失效
- **到达步数验证**：首页→今日课程=1 击；任意模块=首页 1 击（大厅 Tab→卡）或首页 2 击；全部 ≤2 步 ✅

### 2.3 页面布局、按钮设置与交互流程

**首页布局（一屏一事）**：
```
┌────────────────────────────┐
│ 早安，宝贝！   🤖💬「今天想学什么呀？」 👨‍👩‍👧│ ← 问候+吉祥物+家长角标
│ ┌────────────────────────┐ │
│ │  📅 今日课程    进度 2/5   │ │ ← 主任务区（唯一视觉焦点）
│ │  🚀 开始学习（≥88px）      │ │
│ └────────────────────────┘ │
│ [继续上次·汉字] [益智游戏] [我的成长] │ ← 仅 3 个次要快捷位
└────────────────────────────┘
```

**按钮体系**（在 `CandyButton` 现有四档上新增一档，零回归）：

| 档位 | 尺寸 | 用途 |
|---|---|---|
| hero（新增） | ≥88px 高 | 每屏唯一主 CTA（开始学习/开始闯关） |
| lg | 64px | 卡片内行动钮 |
| md | 52px | 常规操作 |
| sm | 44px | 次要/工具 |

**三态交互规范**（`Button.tsx` 扩展，配 sfx+触感，反馈 ≤300ms）：
- 按下：translateY(4px) + 立体阴影塌陷（现有机制保留）
- 成功：星星迸出 + 文字气泡「真棒！」（复用 celebrate/speech 鼓励语）
- 撤销：底部 toast「已撤销」5 秒可恢复（新增 `UndoToast` 通用组件）；删除/重置/兑换继续走现有 2 秒「再按一次确认」

**防误触**：全部可点目标 ≥48px；主任务与次要操作视觉差 ≥3 级；家长入口进 PIN 门禁（现有三重防护不动）。

### 2.4 设计令牌（引用彩格调《儿童风格设计系统规范 v1》）

> 完整规范：`docs/2026-08-28-儿童风格设计系统规范.md`（六色四值均按 WCAG 相对亮度公式逐对验算，括号内为实测对比度）

**选型**：Notion（Playful-Neutral 变体）中性暖底作画布 + Duolingo 游戏化按压原则，定制为主、借鉴为辅——现有 CandyButton 果冻阴影与 Duolingo 位移法天然同构，可直接移植。

**六色板**（键名与 `tones.ts` 完全一致，整表替换即全站换肤，74 个消费文件零改动）：

| tone | main | on（main 上深字） | deep（承载白字） | soft |
|---|---|---|---|---|
| pink | #FF5C8A | #3D1424（5.40） | #C9285C（白 5.33） | #FFE1EB |
| orange | #FF9F2E | #4A2B1F（6.19） | #B45F09（白 4.58） | #FFF0DB |
| yellow | #FFC53D | #4A2B1F（8.03） | #8A5B00（白 5.87） | #FFF6D9 |
| green | #3FC26B | #123B21（5.46） | #1B7A3D（白 5.39） | #DFF5E7 |
| blue | #3D9BFF | #0C2D4F（4.87） | #0B5EC9（白 6.07） | #DCEBFF |
| purple | #8F5BFF | #160830（4.60） | #5F2ECC（白 7.64） | #EFE4FF |

- **文字承载双通道**：main 色上用深 on 字，deep 色上用白字——高饱和卡通色**永不承载白字**（实测仅 1.6-2.9:1）
- 语义色：success #3FC26B / warning #FFC53D / error #FF5C8A / info #3D9BFF（复用主色，不引入第七色）
- 中性：底 #FFF8EF 暖奶油 · 卡 #FFFFFF · 描边 #F3E3CF · 正文 #4A2B1F（12.68）· 次级 #8A6F5C
- 字体：Baloo 2 + PingFang SC（中文无圆体，用字重补偿：标题/按钮 900、正文 500，字距 -0.01em）；字号 17/19/22/26/32/44，**正文一律 ≥19px**
- 圆角：卡 24px · 按钮胶囊 9999 · 弹窗 28px · 新增 `--radius-hero: 32px`
- 果冻阴影：静置 `0 4px 0 deep` + 柔影；按压 `translateY(4px)` 硬影归零（Duolingo 位移法）
- 动效：进场 240ms `cubic-bezier(.34,1.56,.64,1)`、按压 90ms、庆祝 600ms（首帧响应 ≤300ms）
- 组件规格：主 CTA ≥88×88（FluffyIcon 32 + 大字 22/900，三态：下沉/变绿对勾/2 秒撤销）· HubCard 渐变头图占 60%+图标 56px+名 22px+朗读角标 · 底导航 72px（图标 32+文字 15）· 吉祥物 96px 固定右下 · 庆祝 ≤1.6s 可跳过
- 栅格与断点：手机 2×2、平板 2×3、≥lg 大厅 3 列；**沿用 lg=1024px 不改**
- 新增令牌：`--color-success` · `--radius-hero` · `--space-hub`（16px）·（建议 `--animate-celebrate`）
- ⚠️ 风险：orange deep #B45F09 白字 4.58 刚过线，**后续调整切勿调浅**
- PC 端取舍：主方案用大厅替代侧边栏；若需保留侧边栏，则按规范折叠为「全部」抽屉、首屏只露 5 个高频模块
