## 1. 范围与发现

本批 4 页（PoemsPage / IdiomsPage / WordsPage / FillBlank 儿歌填词）在**前序轮次**已让子组件大量消费 `poem`/`idiom`/`idioms`/`words`/`song` 命名空间；本轮只补**壳层残留硬编码中文**，故字典增量小、风险低。

| 页面 | 改动 | 字典增量 | 关键手法 |
|---|---|---|---|
| `PoemsPage.tsx` | `清除筛选` → `t('poem.clearFilter')` | +1 键（`poem.clearFilter`） | 复用已有 `t` hook |
| `IdiomsPage.tsx` | `TABS` 3 label（成语故事/猜成语/接龙）→ `translate('idioms.*')` | 0（复用 `idioms.library/guess/chain`） | 模块级常量须用模块级 `translate()`，不能用 hook |
| `WordsPage.tsx` | 15 个 `TABS` label + 8 处页头标题 + 返回 + 加载 + Sight Words 宝盒 | +19 键（`words.tab.*`×15 + `backToList`/`phonics*`/`listen*`/`body*`/`spell*`/`dialogue*`/`sentences*`/`builder*`/`homeSubtitle`/`sightWords*`；`builderTitle` 复用于两处） | 新增 `useTranslation` import + `tr` hook；模块级 `TABS` 走 `translate()`；`common.loading` 复用 |
| `FillBlank.tsx` | 儿歌填词整壳（标题/难度/得分/星/题号/对错提示/下一题/歌词过短提示） | 新建 `rhyme` 命名空间 +13 键 | hook 改名 `tr` 避 `const t = TONE_STYLE[tone]` 遮蔽 |

- 全站已接 `useTranslation`：**36 / 251 tsx（约 14%）**（本轮 +2：WordsPage、FillBlank；PoemsPage/IdiomsPage 此前已计入）。
