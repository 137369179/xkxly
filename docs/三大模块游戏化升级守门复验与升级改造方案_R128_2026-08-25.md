### 3.2 国际早期读写 / 自然拼读 2026 实证与设计原则

- **AI 持续评估 + 自适应**（ReelMind 2026）：多模态（视觉/听觉/动觉）协同；AI 分析参与度实时调整节奏、回退难度、即时干预，避免错误固化。
- **短时高频 + 检索练习**（LiteracyPlanet 2026）：3–5 岁单局 5–10min；**检索练习（retrieval）强于被动重复**；自适应（错则退回、对则进阶）；即时温和反馈。
- **12 周实证增益**（GCompris 整合研究 2026，32 名 5–6 岁）：多感官+游戏化+自适应 → 平均成绩 **+60.9%**（48.75→78.44），学生参与率 **68.75%→93.75%**；**音素意识增益最高 +67.24%**。
- **掌握度进阶硬标准**（Flashcard 研究）：**3 连对且 <3 秒、跨 ≥2 次会话**方判定掌握，方可进阶；间隔重复三档（Unknown 每日 / Hard 每 2–3 次 / Easy 每周）；自比挑战（Beat the clock，刷新自身记录）。
- **频率 > 时长**（ReadFlare）：3×15min/周 优于 1×45min；**警惕"通关快但真实阅读不迁移"** → 需回退难度；卡关超 3 周需人工介入。

### 3.3 研究结论（与 Core Loop v2 高度一致，零方向冲突）

本轮增量研究**未产生新的超范围需求**，仅对既有方案的落地细则给出实证支撑与可量化标准：

1. **形音义三联匹配 + 具象插图** → 强化 phoneme–grapheme–meaning 关联（补强汉字/拼音模块）。
2. **五步法 / 口诀儿歌** → 结构化多步闭环（认形→听音→发音→书空→拼读）。
3. **叙事化探险 + 地图解锁** → 与 Core Loop v2「叙事沉浸支柱」对齐。
4. **3 连对进阶** → 补强「2 胜即停」，给出**正向掌握判定硬标准**（避免 only 负向停止）。
5. **频率 > 时长 + 单局 ≤3–5min** → 实证印证健康节奏三段式断点（超范围待授权）。
6. **自比挑战（beat your own score）** → 非竞争性，与「协作 > 竞争」一致。
7. **检索练习 + 间隔重复** → 印证错字本/间隔复习价值（超范围待授权）。
8. **警惕"通关快但迁移弱"** → 再次实证「掌握度 > 分数」方向正确。
9. **AI 持续评估 + 自适应** → 印证 useAdaptive 动态难度方向。
