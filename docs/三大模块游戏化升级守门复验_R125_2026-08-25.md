### 4.1 渐进式难度设计（对应要求 #2）—— 三段式自适应阶梯

**学术/产品证据（2026.8 新检索）：**
- **自适应阶梯（staircase）**：MDPI  preschool EF 研究（pediatrics.jmir.org, 2025）采用「14 个隐藏关卡 × 每关 3 试次」，逐步递增；**连续 3 次正确 → 响应时限 −500ms（变难）；错误或超时 → 难度保持不变**，确保个体处于「恰到好处的挑战区」。隐藏关卡结构（不显式展示层级）避免儿童焦虑。
- **COCO（Dynseo）自适应引擎**：实时分析「成功率 + 响应时长 + 错误类型」三信号，自动调难度；**无惩罚性 Game Over**，出错即给提示或降级简化，且「阶梯台阶随每次迈步自适应调整高度」，避免羞辱式失败。
- **Steepest Ascent Hill Climbing**（PAUD 拼图，2025）：AI 按玩家能力动态调难度，始终「合适且不单调」。
- **ZPD（Vygotsky，smalluni）**：内容按 i+1 混合——**60% 熟词保信心 / 30% 近期词巩固 / 10% 新词成长**，挑战但不淹没。

**工程实现手册（可复用既有 `useAdaptive`）：**
```
难度状态机 = { level, consecutiveCorrect, responseWindowMs, errorStreak }
规则：
  onCorrect → consecutiveCorrect++；若 consecutiveCorrect>=3 → level++、responseWindowMs=max(base-500*step, floor)
  onError   → level 保持；errorStreak++；若 errorStreak>=3 → 立即轮换题型（情绪安全，见 4.3）、consecutiveCorrect=0
  onTimeout → 同 onError（时限内未答视为困难信号）
关卡对外隐藏为「星星/关卡进度」，不展示数字难度，避免焦虑。
```

### 4.2 间隔重复 SRS 与错字本闭环（对应要求 #5 掌握度 + #2 复习节奏）

**证据（2026.8 新检索）：**
- **Leitner 盒（1972）**：5 盒，答对晋级（间隔变长）、答错回盒 1；可视、可触摸，儿童友好。
- **SM-2（1987）**：每张卡存 `interval / repetitions / EF(初始2.5)`，约 50 行即可实现；grade 0–5 自适应。
- **FSRS（2024）**：ML 记忆模型，目标保持率 ~90%，**同等记忆率下复习量减少 20–30%**。
- **Pimsleur 毕业间隔**：5s→25s→2min→10min→1h→5h→1d→5d→25d→4mo→2y，首数次极短间隔。
- **Duolingo PNAS 自然实验**：算法化间隔 > 其他排程，大规模实证有效；**汉字类体量巨大，算法 SRS 尤为必要**（lingolegend）。
- **Kornell**：短而频的会话 > 长而稀，每日 10–20 新卡上限。

**工程实现手册（复用 R123 错字本框架，升级为 SRS）：**
```
错字本每项 = { char, box(1-5), EF(2.5), nextReviewAt, lapseCount }
复习调度：box1 每日 / box2 每3日 / box3 每周 / box4 双周 / box5 每月
答对 → box++、nextReviewAt=now+interval(box)；答错 → box=1
首学后前 3 次用 Pimsleur 短间隔（秒/分级）固锚；2 胜即停（R110 既定，防 over-rewarding）
```

### 4.3 即时反馈话术与温和引导（对应要求 #3）—— 成长型心智话术库

**证据（2026.8 新检索）：**
- **edsoft 情绪安全四机制**：① **连续 3 次同类错误立即轮换题型**（打断挫败螺旋，本概念下一轮再回）；② 信心 <0.45 给「完整例题」但话术重构为「换一种看法」而非「你错了」，并给小幅信心奖励（不越过掌握阈值）；③ **部分进度条**（65% 进度显示为 65%，非空圈）；④ 60 分钟上限话术「已锁定 2 个概念，下次再来 1 个就通关」——「锁定」措辞把完成概念变银行存款而非待办清单。
- **过程表扬 > 人格表扬（Dweck，smalluni / Gunderson 2013）**：「你真努力！」>「你是天才！」；错误时「这个有点难，我们换个方式再试一次」。应用反馈语言在塑造学习关系，非装饰。
- **editorialge 2026 家长评测**：弱反馈「Wrong. Try again.」vs 优反馈「给线索/解释/示范/下一步」；并警示**奖励循环过载**——徽章/进度可选，但若孩子只为金币/头像回来而非为技能，应暂停重估。
- **eathealthy365**：正确→奖励音/动画/积分（正向强化）；错误→中性音/「再试一次」（去失败刺痛）；私密安全试错空间。

**工程实现手册（话术库 + 行为规则）：**
```
正确：celebrate() 动效 + 过程表扬话术池["你做到了！","又进步啦","这个记得真牢"]
      随机抽取，避免机械重复；配合 celebrate 动效（32 处已接）
错误：中性音 + 一步提示（指错因，非直接给答案）+ 话术池["这个有点难，换个方式试试","再想一想，你可以的"]
      errorStreak>=3 → 题型轮换 + 降级提示（见 4.1）
进度：partial progress bar 始终显示真实百分比；关闭用「已学会 X 个，还差 Y 个就解锁」
禁用：红叉❌ / "错误" / "失败" / 倒计时羞辱 / 任何人称天赋型表扬
```
