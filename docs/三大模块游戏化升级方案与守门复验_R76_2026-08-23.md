8. **家长报告 / 知识图谱 / 进度周报 / 多孩独立账号**——宝宝巴士、SplashLearn、Prodigy 月报

11. **亲子 PK / 对战 / 竞技**（离线+在线）——洪恩对战、Mathletics 全球赛、ABC Reading
12. **无广告 / COPPA·FERPA 合规安全底线**——Khan / SplashLearn / Prodigy / MathHero 共识
