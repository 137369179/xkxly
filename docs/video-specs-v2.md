# 汉字教学视频规格标准 v2.0

## 概述
本文档定义宝贝学习乐园所有汉字教学视频的技术规格和质量标准，确保学习体验的一致性。

---

## 📹 技术规格

### 基础参数
| 参数 | 规格 | 说明 |
|------|------|------|
| 分辨率 | 1280×720 (720p) | 固定比例 16:9 |
| 帧率 | 25 fps | 流畅且文件体积适中 |
| 编码 | H.264 (libx264) | 广泛兼容 |
| 音频编码 | AAC | 128kbps 单声道 |
| 时长 | 50秒 ± 2秒 | 标准教学时长 |
| 文件大小 | 1.0 - 2.5 MB | 平衡质量与加载速度 |

### 色彩规范
- **背景色**: `#FFF8F0` (暖白色)
- **主色调**: 根据声调颜色区分（见下表）
- **文字颜色**: `#1A1A2E` (深墨色)

| 声调 | 颜色代码 | 用途 |
|------|----------|------|
| 一声 | `#FF6B6B` | 红色系强调 |
| 二声 | `#4ECDC4` | 青色系强调 |
| 三声 | `#45B7D1` | 蓝色系强调 |
| 四声 | `#96CEB4` | 绿色系强调 |

## 🎬 内容结构（50秒分段）

### 第1段：引入（0-5秒）
```
[淡入] 大字号汉字居中显示
[配音] "小朋友们好！今天我们学习汉字「X」"
[字幕] 汉字 + 拼音同时出现
```

### 第2段：发音（5-15秒）
```
[配音] "这个字读「X」，是X声。"
[动画] 拼音按字母逐个亮起
[演示] 口型示意（可选）
```

### 第3段：字源故事（15-30秒）
```
[配音] 讲述汉字起源故事
[动画] 字形演变过程展示
[插图] 象形/会意/形声图解
```

### 第4段：组词练习（30-40秒）
```
[配音] "这个字可以组这些词：X、X、X"
[展示] 每个词语逐个出现并朗读
[互动] 提示孩子跟读
```

### 第5段：总结巩固（40-50秒）
```
[配音] "让我们再复习一遍..."
[快闪] 汉字-拼音-组词快速回顾
[鼓励] "你真棒！给自己鼓鼓掌吧！"
[淡出] 结束画面
```

## 🎨 视觉设计规范

### 汉字展示
- **字体**: 楷体或少儿专用字体
- **大小**: 占屏幕高度的40%
- **位置**: 画面上方1/3处居中
- **动画**: 缓慢缩放效果（Ken Burns）

### 拼音展示
- **字体**: 拼音专用字体，带声调符号
- **大小**: 汉字下方，字号为汉字的一半
- **颜色**: 根据声调自动着色
- **动画**: 逐个字母亮起效果

### 词语卡片
- **样式**: 圆角矩形卡片
- **内容**: 汉字+拼音+简单图标
- **动画**: 从右侧滑入，停留2秒后退出

---

## 🔊 语音规范

### 配音要求
- **语音**: 中文女声，语速适中（140字/分钟）
- **音调**: 亲切活泼，适合儿童
- **音质**: 清晰无杂音，无背景音乐干扰

### 文本模板
```
小朋友们好！今天我们学习汉字「{char}」。
这个字读「{pinyin}」，是{tone_name}。
它是个{type}字。{origin_story}
这个字可以组这些词：{words}。
跟我一起读：{word1}，{word2}，{word3}。
小朋友，你学会了吗？真棒！
```

## ✅ 质量检查清单

生成视频后需验证以下项目：

- [ ] 分辨率确认为 1280×720
- [ ] 时长在 48-52秒范围内
- [ ] 文件大小在 0.8-3.0MB 范围内
- [ ] 语音清晰可辨，无断句错误
- [ ] 汉字显示完整，无裁剪
- [ ] 拼音声调正确标注
- [ ] 词语示例合理且常用
- [ ] 动画流畅，无卡顿
- [ ] 色彩符合声调规范
- [ ] 结尾有鼓励性话语

## 🛠️ 生成工具说明

### 使用脚本
```bash
# 生成单个汉字视频
node scripts/gen-hanzi-videos.mjs --char 日

# 批量生成指定范围
node scripts/gen-missing-videos.mjs --level 1

# 验证视频规格
node scripts/validate-videos.mjs --check all
```

### FFmpeg参数
```bash
ffmpeg \
  -loop 1 -i INPUT.png \
  -i INPUT.mp3 \
  -filter_complex "zoompan=z='min(zoom+0.0008,1.15)':x='iw/2-(iw/zoom/2)':y='ih/2-(ih/zoom/2)':d=1250:s=1280x720:fps=25,fade=t=in:st=0:d=0.5,fade=t=out:st=49.5:d=0.5" \
  -map "[v]" -map 1:a \
  -c:v libx264 -preset fast -crf 28 \
  -c:a aac -b:a 128k \
  -shortest OUTPUT.mp4
```
