## 一、P2-3 统一 BFF（aiProxy 同构抽取）✅

### 缺口澄清
`worker/index.mjs`（生产 Cloudflare Worker）与 `server/index.mjs`（Node 本地 dev / 自托管）各自实现 `/api/ai/chat` 代理，模型解析/校验/请求体成型三处逻辑**重复且易漂移**——这是真实的 bug 来源。

### 关键发现（避免误统一）
- 生产 Worker 白名单仅 **4 个 Agnes 模型**（仅配 `AGNES_API_KEY`）。
- 本地 dev 白名单 **8 个模型**（另含 DeepSeek / Xunfei，配三套密钥）。
- 该差异是**凭证可用性驱动的合理差异**，不能强行统一（否则生产暴露无密钥模型、或 dev 无法测 DeepSeek）。

### 方案
新增 `shared/aiProxyCore.mjs`（纯逻辑、双运行时通用、零依赖）：
- `resolveModel(requested, defaultModel, allowedModels)` —— 白名单解析 + 回退（闸门防高价模型盗用）。
- `validateMessages(messages)` —— 结构校验（非空 / ≤20 条 / 合法 role / ≤2000 字）。
- `buildUpstreamBody(payload, model, opts)` —— 上游请求体成型（仅透传白名单字段）。

两处改为 `import { resolveModel, validateMessages, buildUpstreamBody } from '../shared/aiProxyCore.mjs'`：
- **逻辑漂移消除**：解析/校验/成型规则全站唯一真相源。
- **白名单数据保留**在各端（`ALLOWED_MODELS` 作参数传入），尊重凭证差异。
- **儿童安全护栏**（`CHILD_SAFETY_PROMPT` + `INJECTION_PATTERNS`）仅留 Worker（生产必需）；dev 的并发闸门 / 多供应商候选 / DeepSeek JSON 加固保留各端。

### 验证

- `node --check` 三个 `.mjs` 均 OK。

- 线上 `/api/ai/health` → `{"ok":true,"model":"agnes-2.5-flash","runtime":"workers","corsOrigin":"https://xkxly.ccwu.cc"}`。

## 二、P3-5 i18n 分批接线（参考实现）✅

### 状态盘点
- 框架成熟：`useTranslation.t()` 含「当前→zh-CN→原始键名」回退链；`zh-CN.json`/`en-US.json` 各 1429 行、40+ 命名空间。
- 接线覆盖：251 个 tsx 仅约 30 个接了 `useTranslation`（核心 chrome：TopBar/BottomTabs/Sidebar 已接）；**剩余约 215 个未接线**，为产品级分批工程。

### 本轮交付（首屏参考实现）
- `useTranslation.ts` 新增模块级 `translate(key, params)`（供非组件函数用，复用同一字典与回退链）——可复用工具。
- `HomePage.tsx` 完整接线（首屏最高可见度）：
  - 新增 `home.*` 双语 key **17 个**：`companionPark` / `companionParkDesc` / `loadingMap` / `loadingMilestone` / `loadingTree` / `masteryTitle` / `masteredTouched` / `masteredDone` / `masteryRateLabel` / `nextBadge` / `todayNotStarted` / `todayReview` / `reasonNotStarted` / `reasonMorePractice` / `reasonProgress` / `reasonGood` / `modWords`。
  - 复用 `nav.*` 命名空间（模块短名如 字母/数字/古诗…）。
  - `reasonFor` 等模块级函数改用 `translate()`。

### 接线模式（后续批次照此）
1. 在组件中 `import { useTranslation } from '@/i18n/useTranslation'`，JSX 用 `const { t } = useTranslation()`。
2. 模块级函数用 `translate(key, params)`（无需 React 上下文）。
3. 硬编码中文 → 点分 key；key 必须**同时**写入 `zh-CN.json` 与 `en-US.json`（否则 en 缺键会回退到 zh-CN 中文，虽不露 key 路径但非英文）。
4. 动态句式用 `{name}` 插值参数化。

   ```bash

   npx wrangler secret put AGNES_API_KEY
   # 粘贴新密钥（回车确认；私密，不会回显）
   # 可选：npx wrangler secret put DEEPSEEK_API_KEY
   # 可选：npx wrangler secret put XUNFEI_MAAS_API_KEY
   ```

> 注：密钥经 `wrangler secret` 注入 Worker 运行时环境变量，前端 bundle 永不接触；轮换无需改代码、无需重新构建。

## 四、P2-5 / P3-4 评估定稿 ⏸（暂缓，非造假）

| 项 | 结论 | 理由 |
