# 桌面宠物系统专业级升级设计（R90）

> 日期：2026-08-22 ｜ 模块：`src/modules/pet/desktop` ｜ 状态：设计已确认
> 决策链：RPG 属性模式 → 属性+进化阶段 → 全站学习行为联动 → 效用驱动自主行为+情境对话 → 雷达图+分页签 UI → 渐进式重构

## 1. 目标

将现有 12 模块桌面宠物升级为专业级养成系统：宠物随孩子**全站学习行为**真实成长（RPG 属性），阶段**进化**带来可见形象变化与解锁，**效用 AI** 驱动自主行为与主动陪伴，UI 以**雷达图+分页签**重构，配套单元/集成/体验三层测试计划。

## 2. 架构总览（渐进式重构）

保留现有纯逻辑层模式，新增：

```
src/store/usePetLinkStore.ts        # 全局学习行为事件总线（zustand，零新依赖）
src/modules/pet/desktop/lib/
  attributes.ts                      # RPG 属性引擎（纯函数）
  evolution.ts                       # 进化引擎（纯函数）
  behavior.ts                        # 效用行为引擎（纯函数）
```

- `petReducer`：state 新增 `attributes / evolution / behavior`；action 新增 `gain-attr / evolve-check / behavior-step / behavior-cool`
- 数据迁移：localStorage `xkxly_desktop_pet_v1 → v2`，旧 `affinity.exp` 1:1 映射为好感维初始 exp
- 接入方式：各学习模块完成回调一行调用 `usePetLinkStore.getState().report(kind)`，集中映射表不改业务逻辑

## 3. RPG 属性系统（5 维）

### 3.1 维度与来源（全站联动）

| 维度 | 来源 kind | 单次 exp | 每来源日上限 |
|---|---|---|---|
| 🧠 智力 | letters / hanzi / pinyin / poems / words | +8 | 6 |
| 🧠 智力 | numbers（算术） | +10 | 6 |
| 💪 体质 | pomodoro（宠物内番茄钟完成） | +15 | 5 |
| 💪 体质 | games（游戏中心）/ logic（逻辑挑战） | +10 | 5 |
| ✨ 魅力 | songs / music | +8 | 5 |
| ✨ 魅力 | art（画画） | +10 | 5 |
| 🎨 创造 | pixel（拼豆保存）/ storybook / story | +10 | 4 |
| ❤️ 好感 | 现有 8 类互动（原系统并入，数值不变） | 6~20 | 沿用 |

防刷：同来源最小间隔 60s + 日上限；好感维沿用既有每日上限表。

### 3.2 等级公式（每维统一）

- `Lv = min(10, 1 + floor(exp / 50))`，每 50 exp 一级
- 雷达图归一化上限：Lv10 = 450 exp
- 满勤节奏 ≈ 9–12 天全满（用户确认保持）

### 3.3 事件总线（usePetLinkStore）

```ts
report(kind: AttrSourceKind): { gained: number; capped: boolean }
```
- 内部去重（60s 间隔）与日计数；命中则派发 `gain-attr`
- 页面加载时不重放历史；仅实时行为计入

## 4. 进化系统

### 4.1 阶段表（用户确认：阈值提前+槽位提前）

| 阶段 | 总等级 | 形象 | 动画幅度 | 配件槽 |
|---|---|---|---|---|
| 🥚 蛋 | 1 | 蛋形微晃 | ×0.6 | 2 |
| 🐣 幼年 | 2–3 | 小号形象 | ×0.8 | 4 |
| 🐱 少年 | 4–6 | 中号形象 | ×1.0 | 5 |
| 🦁 成年 | 7–10 | 大号形象 | ×1.15 | 7（全解锁） |

- **总等级** = `round((智力+体质+魅力+创造+好感 各Lv之和) / 5)`
- 配件按 `ACCESSORIES` 声明顺序解锁前 N 件；蛋阶段即可戴 2 件
- 进化只前进不回退（`evolution.stage` 单调递增）
- 图鉴：记录各阶段首次达成时间戳，面板可查看

### 4.2 进化庆祝

- `evolve-check` 检测总等级跨阈值 → 全屏 motion/react 动画（光效+粒子爆发+阶段文案 2.8s）
- 期间暂停行为决策；结束后写入图鉴

## 5. 效用行为引擎（Utility AI）

### 5.1 行为集与效用分（用户确认：更活跃主动）

| 行为 | 分值 | 修正 |
|---|---|---|
| sleep | 夜(22-6)=0.95 / 21-22=0.6 / 其余 0.05 | 在家 +0.3 |
| wander | 白天 0.5 × 时段活动系数 | — |
| play | 白天 0.55 | 好感 Lv≥3 +0.1 |
| invite | >10min=**0.7** / >30min=**0.85** | 冷却 **10min** 内强制 0 |
| study | 智力为最低维（含并列最低）且白天 → 0.7 | 冷却 **20min** 内强制 0 |
| eat | 白天 0.3 | — |
| goHome | 夜晚未在家 0.8 | 已在家强制 0 |
| idle | 0.4 兜底 | — |

### 5.2 决策机制

- 决策周期 **3s**（用户确认更活跃）；当前行为迟滞 +0.15 防抖
- `invite`：气泡「陪我玩一会儿吧！」+ 爱心粒子，点击宠物视为响应
- `study`：基于全站掌握度数据选薄弱模块（复用个性化注入基础），气泡「我们去练 XX 吧！」，可跳转对应路由
- `sleep`：宠物闭眼 + zzz 粒子，点击可唤醒（唤醒后 10min sleep 效用 -0.3）

## 10. 风险与对策

| 风险 | 对策 |

| 全站接入点分散、易漏 | 映射表集中管理；第一期限定 11 个来源；漏报仅少加经验不影响稳定 |
