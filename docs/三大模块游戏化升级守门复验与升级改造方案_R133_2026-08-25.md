## 二、2026.8 语音评测/AI纠音专项研究（本轮核心增量 · NEW · S 层）

任务要求「**即时反馈机制，正确操作给予积极强化，错误操作给予温和引导**」（要求#3）。在识字/拼音/古诗模块中，「读准字音」是核心动作，但语音维度的即时反馈（ASR 纠音）是 R1–R132 研究中**唯一持续被标为「待授权」却始终未落地**的增强项（TTS/纠音/语音评测）。本轮补全此缺口，结论直接映射「沉浸式互动主动学习」与要求#3。

### 2.1 国内竞品 2026.8：跟读/AI纠音已成识字闭环标准环节
- **宝宝巴士汉字 V9.91.22（2026.8.12 更新）**：五步识字法「认·学·读·写·练」，**「多模式跟读练字音」为独立一环**；AI 智能复习 + 精灵岛主动复习 + 识字表三态（已学/未学/学错）；覆盖 1900 字。
- **帮帮识字**：AI 语音纠正（真读真写），单字互动 + AI 纠音，激励设计丰富。
- **洪恩识字 V4.4.6**：AI 学伴「川川」语音陪练，七步闭环（玩·认·练·写·测·复习·阅读）。
- **悟空/熊猫博士**：均含跟读发音环节（悟空每天 10 分钟固定节奏、熊猫博士星际剧情驱动跟读）。
- **横向测评共识（2026 家长向）**：跟读有标准普通话发音 + 系统智能纠音；缺点警示——帮帮「游戏频次偏高，孩子易把重心放在游玩而非识字」→ 印证既有「2 胜即停 / 掌握度>分数」方向正确。

### 2.2 国际实证：Duolingo ABC 语音识别的双面教训（关键设计输入）
- **有效面**：语音识别让孩子「读出来它判断对不对」，发音不标准温柔让再试一次；音频**本地处理、不存储**（Pastory 实测：microphone audio processed locally, not stored for profiling → COPPA 友好）。
- **警示面①（准确率）**：Educational App Store 实测——语音识别对成人音优化，对低龄儿童口齿不清**易误判**，且「过于宽松常把错误当正确」；可能伤害自信。
- **警示面②（可降级）**：可一键关闭语音功能，退回人工/文字反馈，避免打击自信。
- **设计共识（Phonics.org）**：纠音应聚焦「自然拼读解码（sounding out）」而非整词匹配；无时间压力、错误无惩罚、重读示范即放行。

### 2.3 收敛：S 层（语音反馈层）落地细则
| 编号 | 细则 | 设计依据 |
|---|---|---|
| **S1** | **端侧 ASR**（Web Speech API / 端侧模型），音频不外传、不存储 | Duolingo 本地处理 + COPPA/个保法（L 层合规协同） |
| **S2** | **宽容置信阈值 + 三维评分**（声母/韵母/声调），仅「明显偏差」才纠，避免误伤 | Duolingo「过于宽松误判」反例；低龄口齿不清容错 |
| **S3** | **温柔引导闭环**：错不说「错」→「再试一次，听老师读~」+ 重播标准音；最多 2 次后给示范并放行 | Productive Struggle / 2 胜即停 / 错误无惩罚 |
| **S4** | **可关闭降级**：家长/儿童一键关语音，退回「文字+点击发音」反馈，绝不阻断学习主线 | Duolingo 可关闭避免打击自信 |
| **S5** | **即时反馈映射**：跟读正确 → celebrate 动画 + 积分 + 连击；跟读作为五步「读」环节 | 要求#1/#3/#4 |
| **S6** | **进度成就挂钩**：纠音通过次数计入掌握度与成就系统（与 G4 闭环） | 要求#5 |

**与 Core Loop v2 一致性**：S 层是「即时反馈」（要求#3）在**语音模态**的闭环补全，与既有视觉/动画反馈（celebrate/StreakBar）正交，零冲突。
