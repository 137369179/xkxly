### 1.3 健壮性弱点
- 多处 `speak(...)` 语音、`<audio>/<video>/<img>` 媒体加载、AI 讲解调用处于裸调用状态，失败时可能抛出未捕获异常，在儿童端造成整页崩溃。
- `HanziStrokeWriter` 的笔顺 JSON 加载仅有 `try/finally` 缺 `catch`，资源缺失会 reject 未处理。
- `HanziVideoCard` 的 IndexedDB 取 Blob URL 无降级，离线缓存不可用时弹层可能打不开。

## 二、改造目标

1. **闭合学习闭环（最高优先级）**：三大模块全部「判定对错」的练习 100% 回写统一 SRS 掌握度，使家长报告与自适应难度曲线获得真实数据。
2. **稳定性**：消除练习过程中的未捕获异常，音频/媒体/AI 失败优雅降级，绝不整页崩溃。
3. **代码规范统一性**：维持 0 ESLint error；新增回写调用统一采用 `practice(skill, correct, stars, difficulty)` 范式与稳定的 skill key 命名空间。
4. **运行性能**：不引入额外渲染开销；异步语音调用以 `.catch` 静默降级，避免 Promise 浮动。
5. **长期可维护性**：skill key 命名空间按模块收敛（`hanzi:*` / `pinyin:*` / `letter:*` / `word:*` / `math:*` / `logic:*`），便于后续报表与难度系统聚合。
