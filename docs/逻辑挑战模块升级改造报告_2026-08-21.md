## 四、具体实施内容（已落地）

### 4.1 新题型：条件判断（🚦 `makeConditionQuestion`，核心新增）

三档难度递进（对齐认知发展阶梯）：

| 档位 | 年龄段 | 子题型 | 说明 |
| --- | --- | --- | --- |
| **L1** | 3-4 岁 | 生活分类 | 会飞吗 / 是水果吗 / 是动物吗 / 是红色吗 / 可以吃吗 / 会游泳吗——6 组图形归类，零文字门槛 |
| **L2** | 5-6 岁 | 真假判断 + 场景规则 | 「哪句话是对的/错的」（6 真 6 假陈述池）；「红灯亮了怎么做」「下雨带什么」等 4 组生活规则（50% 轮换） |
| **L3** | 7 岁+ | 多条件推理 | 属性交集（既是动物又会游泳）、大小传递（大象>小狗>小猫谁最大）、数量推理（每人 2 块饼干 3 人共几块） |

- 每题含 `prompt / speak（语音）/ hint（即时提示）/ why（AI 讲解引导）/ skill: logic:condition`。
- `LogicKind` 扩展为 `pattern | match | order | condition`；`makeLogicQuestion` 与 **mixed 综合池**同步纳入 condition。

### 4.2 难度分级可视化（对齐帮帮识字分龄体系）

- 难度按钮组升级为「档位 + 年龄段徽标」：**入门 · 3-4 岁 / 进阶 · 5-6 岁 / 挑战 · 7 岁+**。
- 自适应难度（`useAdaptiveDifficultyState` + RoundRunner 连对/连错校准）保持不变，出题难度实时动态调整。

### 4.3 游戏化：逻辑小达人进度条

- 新增 `LogicStats` 常驻统计条（🦉）：累计答题数 / 答对 / 正确率百分比，数据源自 `progress.logicCorrect/logicTotal`（SRS 回写自动累计）。
- 未作答时显示鼓励文案「快来挑战第一题吧！」；正确率徽章（⭐ X%）即时反馈成就感。

### 4.4 界面与双语

- PageHeader 副标题更新为「找规律 · 配对 · 排序 · 条件判断」（双语）。
- 新增 tab「条件判断 🚦」（置于「排序」与「综合」之间），支持深链 `#/condition`。
- i18n：zh-CN / en-US 各新增 8 键（pageSubtitle / tabCondition / ageBegin / ageAdvance / ageChallenge / statsTitle / statsEmpty / statsLine）。
