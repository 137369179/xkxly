## 3. 游戏化新模块研究验证（2026.8 新检索，针对本轮 WIP 新方向）

### 3.1 ParentChildDuel —— 社交协作支柱（2026 国内双人/亲子互动研究）
来源：PP助手 2026 双人榜单、九游 2026、豌豆荚 2026、25pp 2026 等一致指向以下设计原则：
- **非竞争性目标** / 失败**不设惩罚机制** / 「过程重于结果」；
- **协作模式优先**于对抗（共用道具、同步动画、协同决策）；
- 即时正向反馈、阶梯式难度、**单局 ≤3–5 分钟**（契合儿童用眼健康）；
- 左右分屏清晰归属、无文字即可理解规则、**温和复盘引导**。
> 与既有 Core Loop「协作>竞争 / 排行榜可退出分组 / 温和引导」方向高度一致。建议 `ParentChildDuel` 落地：**默认协作模式**、错误无惩罚+「再试一次」、单局计时、家长可同屏。

### 3.2 storybook —— 叙事沉浸支柱（2026 国际研究）
- **ARtistic Tales**（ACM 2026）：AR 故事书 = 角色动画 + 同步 narration + 理解测验 + 拼写练习 + token 奖励；每日目标→勋章（精度&一致性）→streak 仪表盘→解锁新故事/AR 主题。
- **AnswerHarbor**（2026.2）：互动绘本 = 动画+音效+触控；「Read to Me」**逐词高亮跟读**；**点词→发音/释义**；分支叙事培养因果推理。
- **Materlu**：个性化（孩子是主角）、分支选择、亲子共读（强化家庭联结）、技术增强而非主导。
- **FasterCapital**：点词发音（Dr.Seuss）、Nosy Crow 动画+互动触点+叙事内小游戏、StoryToys 3D 立体书、Disney Frozen 故事书。
> 与新增 `storybook/engine(GradedBookEngine)` 方向一致：**分级读物引擎 + 逐词高亮跟读 + 点词释义 + 叙事内微游戏 + 勋章/解锁闭环**。验收建议：引擎须接 `StreakBar`/勋章/解锁，逐词高亮+点词发音复用既有 TTS。

### 3.3 hanzi/course —— 分级课程支柱（2026 竞品验证）
