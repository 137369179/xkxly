## 一、方向一：薄弱点→专项训练一键路由 ✅

**目标**：家长报告识别出薄弱知识点后，孩子端一键直达对应专项训练，闭合「识别→干预」链路。

### 落地内容
| 文件 | 职责 |
|---|---|
| `src/lib/skillRouting.ts`（新增） | 机制核心：`skillToTarget(skill)` 把 SRS skill key → `{route, param, label}`；`openTraining(skill)` 一键导航；`paramToTarget(route,param)` 反向解码横幅文案；`SUB_LABELS` 为各模块子活动中文标签的**单一事实源**（如 `math:fraction`→`数学·披萨分数`） |
| `src/hooks/useTrainingTarget.ts`（新增） | 订阅 hash 深链 param，返回 `{target, clear}`，param 变化才刷新引用 |
| `src/components/TrainingBanner.tsx`（新增） | 「🧭 专项训练中」横幅，可关闭（clear 回普通路由） |
| `src/modules/parent/ParentPage.tsx`（修改） | 薄弱知识点卡片新增「🎯 去练习」按钮 → `openTraining(skill)` |
| 6 个模块页（修改） | HanziPage / NumbersPage / LettersPage / WordsPage / PinyinPage / LogicPage 消费 param，到达即自动切入对应专项（如 `#/numbers/fraction`→分数游戏、`#/hanzi/stroke:木`→笔顺、`#/logic/maze`→迷宫），并显示横幅 |
| `src/lib/skillRouting.test.ts`（新增） | 33 个用例，覆盖全部命名空间映射与未知 key 兜底 |

### 深链约定（一次建立、全站复用）
`#/hanzi/<字>`、`#/hanzi/stroke:<字>`、`#/hanzi/build:<字>`、`#/numbers/<子技能>`（fraction/money/shape/skip/time/compare/rabbit/tenframe/trace/word/ladder/count）、`#/letters/<字母>`、`#/letters/trace:<A>`、`#/letters/order`、`#/words/{sentence|dialogue|phonics|practice}`、`#/pinyin/{tone|blend|dictation|group}`、`#/logic/{maze|sudoku|codebot|pattern|...}`。

## 二、方向二：错题因果聚类分析 ✅

**目标**：按根本原因（题型/技能类别）归并错题，替代原先仅按命名空间首段的粗分类，让家长一眼看到「到底哪类能力在拖后腿」。

### 落地内容
| 文件 | 职责 |
|---|---|
| `src/lib/wrongCluster.ts`（新增） | `rootCauseOf(skill)` 细粒度根因映射（如 `hanzi-stroke:*`→`汉字·笔顺`、`math:fraction`→`数学·披萨分数`、`pinyin:tone`→`拼音·声调`、`word:phonics:*`→`单词·自然拼读`…）；`clusterWrongBook(progress)` 按根因归并并降序输出 `{key,label,count,skills}` |
| `src/modules/wrongbook/WrongBookDashboard.tsx`（修改） | 新增「🧩 按原因」tab：分组卡片（原因标签、错题数、示例、每组「🎯 去练习」直达对应专项） |
| `src/lib/wrongCluster.test.ts`（新增） | 27 个用例，覆盖映射、归并、排序、空错题本 |

### 与既有能力的关系
沿用 `Progress.wrongBook` 只读聚合，不改数据结构；与方向一的 `openTraining` 打通——每个根因组都能一键进入对应专项训练，形成「聚类诊断 → 定向练习」闭环。
