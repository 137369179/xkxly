设计要点（对应原始任务五条要求）：
1. **独立游戏化玩法 + 奖励解锁**：每个模块一张专属探险地图，跨过里程碑即触发 `celebrateBig()` 庆祝横幅（🐉 汉字 / 🌈 词语 主题）。
2. **渐进式难度**：里程碑 5→20→50→100 递进，进度条按区间百分比平滑增长（motion spring），给孩子「下一关还差 N 个」的清晰预期。
3. **即时反馈**：正确积累达阈值即弹出解锁成就横幅，3.2s 自动收起，与既有 `celebrateSmall/Big` 反馈体系同源。
4. **色彩丰富 + 动画生动**：果冻粉玫瑰红（汉字）/ 翠绿（词语）渐变卡片、圆角里程碑节点、`lock→emoji` 状态切换、弹簧进度条，符合儿童审美。
5. **进度追踪 + 成就系统**：`aria-label` 暴露「已认识 N 字 / 已记住 N 词」供无障碍与成长看板消费；里程碑节点即成就墙，形成明确成长目标感。

代码质量约束（与 R144 一致）：零 `any`、零非空断言 `!`、零 a11y 反模式、装饰性视觉元素统一 `aria-hidden`，纯逻辑与渲染分离以便单测。
