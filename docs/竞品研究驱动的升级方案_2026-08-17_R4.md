## 二、竞品研究（权威公开资料整理）

### 2.1 识字类 —— 洪恩识字 / 帮帮识字 / 宝宝巴士汉字

**洪恩识字（3–8 岁，市占领先）**
- **六维闭环**：玩 → 认 → 练 → 写 → 测 → 复习，每学完 5 字触发单元闯关测试，答对解锁奖励动画。
- **字源可视化**：独创「汉字画说」法（如「休」= 人靠树休息），激活右脑图像记忆；每字配字源演变动画、甲骨文对照。
- **AI 笔顺纠错**：屏幕手写识别 + 笔顺动态指引 + 实时书写质量反馈。
- **遗忘曲线驱动复习**：基于艾宾浩斯自动规划复习节点，系统推送待复习字卡（闪卡速记、听音写词）。
- **分龄三层**：低龄启蒙(3–4) / 中龄进阶(4–6) / 大龄冲刺(6–8)，难度与侧重点递进。
- **子集分级绘本**：130 本原创绘本仅用当期已学汉字编写，每 10 字解锁 1 本，降低自主阅读门槛。
- **家长端 + 激励**：学习报告、单次时长管控、护眼模式；虚拟宠物成长激励；「难字歼灭」标记未掌握字。

**帮帮识字（3–8 岁，纯净无广告定位）**
- **七维闭环**：学 → 认 → 读 → 练 → 写 → 测 → 复习；1300 字覆盖小学低年级新课标。
- **形义溯源 + AI 纠音**：每个汉字字形字义溯源动画；AI 语音识别实时纠音，真读真写。
- **家长可视化 + 隐私**：自动生成周度学习报告、自定义每日识字量；学习记录本地加密存储。
- **无广告纯净环境**：拒绝游戏化干扰与广告插入，保护低龄专注力。

**宝宝巴士汉字**
- 闯关式互动学习汉字，结合生活场景巩固记忆；分龄分领域设计，智能推荐课程；「任务成就墙」可视化里程碑；虚拟勋章动态奖励。

**共性提炼（识字）**：闭环完整性 · 字源/形义可视化 · 遗忘曲线复习 · 分龄分层 · 家长数据可视化 · 激励体系 · 纯净低龄友好。

### 2.2 英语类 —— 叽里呱啦 / 伴鱼绘本 / ABC Reading

**叽里呱啦（0–8 岁，哈佛教研背书）**
- 体系对标新课标 / 剑桥（Y 体系课 L0–L6），100+ 生活主题，1200+ 核心词汇 + 117 组自然拼读规则。
- **闭环**：趣味动画 + 外教实景双场景；每周五天（前两日学新知、中间练拼读、末复习），单节 ≤15 分钟匹配低龄专注力。
- **OMO 闭环**：配套点读笔、纸质绘本、练习册，「线上学 + 线下练」。

**伴鱼绘本（3–8 岁，分级阅读）**
- A–Z 蓝思分级（牛津树 / 大猫 / RAZ），4000+ 册；**「讲-听-录-练」闭环**；AI 跟读逐句打分；5 分钟定级测试生成个性化计划；小鱼币激励。

**ABC Reading（好未来，正版 RAZ）**
- aa–Z2 共 29 级 2000+ 册；单词预习 → 绘本跟读 → 趣味 Quiz；亲子 PK；「磨耳朵」后台循环。

**共性提炼（英语）**：分级体系(A-Z/RAZ/CEFR) · 跟读 + AI 打分纠音 · 生活场景化 · 闭环(预习-学-练-测-报告) · 激励 · 家长可视化。

### 2.3 数学类 —— 宝宝巴士数学 / 洪恩数学 / 摩比

**宝宝巴士数学**
- **具象化教学**：用「水果切块」教分数、「超市找零」学加减法、「宝宝玩加减法」20 以内点数互动；阶梯运算；逻辑分类 / 配对。
- 分龄推荐、互动课堂（触摸 / 拖拽）、动态奖励（虚拟勋章）。

**洪恩 / 摩比思维**
- 数与量、逻辑关系、阶梯式训练；把抽象概念转化为可操作游戏。

**共性提炼（数学）**：具象化（抽象→生活场景）· 游戏化互动（拖拽/配对/闯关）· 分阶难度 · 即时反馈 · 家长报告。

### 2.4 跨品类共性设计原则（升级对标锚点）

1. **闭环完整性**：每个知识点必须走完「学 → 练 → 测 → 复习 → 激励」且复习由遗忘曲线驱动。
2. **可视化溯源**：抽象概念（字形/词义/数量/语法）必须有图像/动画/生活场景支撑。
3. **分龄分层**：按年龄 + 能力双轴动态调整难度与内容密度。
4. **即时反馈 + AI 纠音/纠错**：书写笔顺、口语跟读、运算结果实时校正。
5. **家长可视化**：学习报告、薄弱点、时长管控、隐私保护。
6. **激励体系**：星星 / 徽章 / 宠物 / 成就墙，内驱力驱动。
7. **纯净低龄友好**：无广告、单指操作、护眼、防误触。
8. **双语 / 出海基础**：文案全量 i18n，中英文均可解析（本轮重点加固）。
