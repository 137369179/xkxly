### 2.4 提炼：跨品类游戏化原则（更新至 2026，共 15 条）

1. **分阶段 / 渐进难度**（洪恩三阶段、帮帮启蒙-强化-提升、叽里呱啦进阶路径）→ 对应需求②
2. **多环节闭环**（玩认读练写测复习）→ 对应需求①独立玩法
3. **即时反馈 + 温和引导**（洪恩"错了提示、对了鼓励"、叽里呱啦跟读打分）→ 对应需求③
4. **积分 / 星星 / 连胜 / 奖励解锁**（帮帮星星商城、洪恩小星星、Prodigy 奖励）→ 对应需求①
5. **成就系统 / 勋章 / 称号 / 进度条可视化**（帮帮勋章称号、洪恩虚拟宠物、Prodigy 徽章）→ 对应需求⑤
6. **亲子互动 / 亲子竞技**（洪恩亲子竞技、宝宝巴士家长管理）→ 亲子共学
7. **家长中心 / 学习报告 / 时长锁**（洪恩、叽里呱啦、宝宝巴士）→ 家长可控
8. **自适应难度**（Prodigy、Mathletics AI、Khan 自适应）→ 智能化渐进（需求②进阶形态）
9. **虚拟养成激励**（洪恩宠物、帮帮养成道具）→ 长期粘性
10. **艾宾浩斯复习曲线**（帮帮、洪恩复习）→ 科学巩固
11. **生活场景沉浸**（帮帮、宝宝巴士）→ 知识迁移
12. **角色 IP 陪伴**（宝宝巴士角色、Kodi 熊、Prodigy 巫师）→ 情感连接
13. **知识迁移 / 阅读输出**（洪恩子集绘本仅用已学字、帮帮绘本联动）→ 学以致用
14. **护眼 / 防沉迷成 2026 头号卖点**（古古 0 游戏 + 蓝光过滤 + 定时休息；4 款"真护眼"实测；硬性时长锁优先）→ 本栈已前瞻布局（R88 护眼 UI 开关 + reduced-motion + motion-density + StudyGuard 定时休息）
15. **纯净无广告 / 低干扰**（叽里呱啦、Khan、洪恩）→ 儿童 App 安全底线
