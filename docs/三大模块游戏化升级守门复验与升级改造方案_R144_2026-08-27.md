### 2.3 具体实施内容
1. **新增 `src/modules/numbers/MathStarQuest.tsx`**（约 175 行）
   - 纯函数 `getMathQuest(mathCorrect)`：根据累计答对题数推导「当前里程碑 / 下一目标 / 区间进度% / 已解锁数」，便于单测、无副作用。
   - 四级里程碑（与成就徽章语义对齐）：🌱数感萌芽(5) → 🔢计算小能手(20) → 🧩逻辑小博士(50) → 🏅数学小院士(100)。
   - `MathStarQuest` 组件：果冻粉渐变卡片 + 里程碑节点（已解锁点亮 / 未解锁 🔒）+ 动画进度条 + 「再答对 N 题解锁 X」引导文案 + 跨里程碑 `celebrateBig()` 庆祝横幅（`prefers-reduced-motion` 自动降级）。
   - **严格零 `!`、零无用赋值、零 `any`**，a11y 文案经 `aria-label` 与可见文本双通道提供，装饰元素 `aria-hidden`。

3. **新增 `MathStarQuest.test.ts`**：7 项单测覆盖纯函数边界（负数/起点/各里程碑进度%/超额），已全绿。
