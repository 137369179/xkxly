## 三、本轮真实回归与修复（重要）

全量 `tsc -b` 报：`src/components/gamification/GameHud.test.tsx(18,5): error TS2769: No overload matches this call`。
**根因**：测试中 `createElement(GameProvider, {getProgress, scene}, child)` 的 `GameProviderProps.children` 为必填，导致 React `createElement` 重载不匹配。
**修复**：把子节点移入 props 对象（`children: createElement(GameHud, {...})`），**零生产代码改动**，复验后 `tsc -b` 错误列表不再含本文件。
