## §3 总体目标与改造原则

**目标**：在不引入新业务域、不改写已生产就绪核心逻辑的前提下，将游戏化激励体系**全覆盖至每一个功能模块**，使全站学习体验达成任务书五项硬性要求，达到可直接商用上线的质量标准。

**原则**：
1. **严格限定现有模块**：仅优化/重构既有文件，零新增业务模块、零新增第三方依赖。
2. **复用基础设施**：所有激励通过既有 `RoundRunner+StreakBar`、`lib/feedback`、`useStars`、`BadgeUnlock`、`DailyQuest`、`medals` 实现，新增代码量最小化。
3. **优先重构既有逻辑**：WhackAMole 等本地 score 直接改造为接入全局 stars，而非另建体系。
4. **零回归**：每模块改造后须通过四门禁（tsc 0 / vitest 全绿 / lint 不超基线 / build 成功）。
