## 1. 概述与定位

### 1.1 方向决策（已定 · 循证）

> **方向名称：「好奇心驱动的多模态精熟闭环」**（**C**uriosity-driven **M**ultimodal **M**astery **L**oop，CMML）
>
> 本方向已由主理人（游承峰）基于一份学习科学循证综述拍板；**仅在用户明确要求时调整**。原清单第 3 节功能点优先级 / 范围据此方向校准（见 §6 修订后的落地顺序）。

**7 步闭环模型**：

1. **好奇心触发**：用现有 Explore 组件的"信息缺口"（如"恐龙为何灭绝？"）激发儿童内在好奇（Loewenstein 1994 知识缺口理论；Gruber et al. 2014 好奇激活多巴胺 / 海马增强记忆）。
2. **多模态探索**：图 + 语音 + TTS 双重编码（Paivio 1971 双重编码 / Mayer 多媒体学习），以具体形象让 5–10 岁绕过抽象语言门槛快速"懂"。
3. **AI 知识卡精细加工**：用 `/api/content/generate` 生成讲解卡，做"自我解释式"精细加工（Bisra et al. 2018 自我解释元分析）。
4. **短提取测验**：RoundRunner + QuizCard 做 3–5 题主动回忆（Roediger & Karpicke 2006 测试效应）。
5. **间隔 SRS 巩固**：`practice()` → SRS + 错题库，间隔重复（Donovan & Radosevich 1999 d=0.42；Sobel et al. 2011 五年级 d=0.48）。
6. **DDA 脚手架递进**：`useAdaptiveDifficultyState` 守 65–85% 心流区，未达标给提示不推进（Vygotsky 1978 ZPD / Bloom 1984 精熟学习 d=0.52）。
7. **游戏化回流**：徽章 / 探索地图奖励"探索行为"而非"答对结果"，回流好奇心（Deci & Ryan 1999 SDT 元分析）。

**为何比纯刷题更快更牢**：先建意义（好奇心包住提取练习，Kang 2009 好奇增强记忆）再巩固；双重编码缩短"懂"的路径；即时反馈 + 精熟把错误消灭在当轮，避免间隔重复把错误也练熟；心流维持动机使总练习时长更高而感知负荷更低。

> 说明：原清单（修订前）将研究模式定位为"drill 的互补型好奇心闭环"，其可复用资产（Explore 组件 / AI 端点 / RoundRunner / SRS / DDA / 徽章）与 4 处路由接线结论**仍然成立**，但功能点优先级与范围已按上述 CMML 方向重新校准（见 §3 F17–F19 新增、§6 落地顺序修订）。

### 1.2 目标年龄
≈5–10 岁（与现有 AI 内容站 `ageRange` 默认 `7-8`、各 Explore 组件受众一致；下端 5 岁需更短的媒体与更口语化 AI 文案）。

### 1.3 与现有 Explore 组件 / 内容站的关系
- **Explore 组件**：现有 `ColorExplore`、`VehicleExplore`、`JobExplore`、`DinoWorld`、`SpaceExplorer`、`BodyAdventure` 是**逐主题、非统一模式**的自包含组件（各自内嵌媒体、玩法、反馈）。研究模式应**优先编排复用**它们作为"探索媒体槽"，而非推倒重做。
- **AI 内容站（`content`）**：已跑通"生成 → KV 持久化 → 浏览"闭环（`generateContent` / `listContent` / `ContentStationPage`）。研究模式的"AI 知识面板 / 发现画廊"应直接复用该闭环与 KV 通道，避免重复造 BFF。

### 1.4 与 drill 模式的边界
| 维度 | drill / quiz 模式 | 研究游戏模式（拟） |
|---|---|---|
| 主体循环 | 出题 → 作答 → 反馈 | 选题 → 探索 → 记录 →（轻量）测验 |
| 题库来源 | 静态 TS + 程序化生成器 | 主题库（静态）+ AI 生成知识（讲解层） |
| 即时反馈 | 每题 hint / AI 讲题 | 探索中媒体反馈 + 知识卡片沉淀 |
| 进度落点 | `practice()` → SRS / DDA | 同左，复用 `practice()`，新增 `research:` 技能命名空间 |

### 1.5 设计原则映射（循证）

|---|---|---|---|---|

| 2 | 间隔重复（SRS） | ★★★ 最硬（Donovan & Radosevich 1999 d=0.42；Sobel et al. 2011 五年级 d=0.48） | `srs.ts` + `practice()`（F9） | — |
| 3 | 即时反馈 + 精熟 | ★★★（Hattie 2009 反馈 d=0.70；Bloom 1984 精熟 d=0.52） | RoundRunner 即时提示 + AI 解析（F7/F4） | — |

**Top3 优先级（按证据强度 + 对闭环的枢纽度）**：
1. **提取练习 + 间隔重复（SRS）**（原则 1+2，最硬证据；由 F7+F9 承载，F17 串接）。
2. **即时反馈 + 精熟 + DDA 支架**（原则 3+4，Hattie 2009 / Bloom 1984 / Vygotsky 1978；由 F7+F8 承载）。
3. **双重编码 / 多媒体**（原则 5，Paivio 1971 / Mayer；由 F3+F11 承载，缩短"懂"的路径）。

> 其中 **G1（闭环编排层 F17）** 是唯一带"新建"性质的核心积木——原则 1–11 的现有资产均已具备，但缺一个把它们串成单一状态机的"研究会话"。设计缺口 G2–G4 对应 F18/F19 与阶段三的交错题序优化。

## 3. 功能点可行性清单（核心）

> 判定图例：**🟢 可实现** / **🟡 受限** / **🔴 需前置**。约束引用：C1=AI 限速与儿童安全护栏强制；C2=AI 仅讲解/生成层（非实时题库）；C3=DDA 绝不回合内重评（须 `onRoundStart` 落档）；C4=新增 Progress 字段须登记 `createInitialProgress()`；C5=PWA 离线预缓存；C6=新路由须同步改 4 处。本清单共 **19** 项功能点（F1–F19）。

### F1 · 模式入口与导航注册
- **描述（儿童）**：首页 / 底部 Tab 出现"🔬 研究乐园"入口，点击进入研究模式。（家长）在"AI / 学习"分类下可见该模块。
- **范围**：in-scope：新增 `research` 路由 + 导航项 + i18n 文案。out-of-scope：改导航引擎。
- **所需逻辑**：`router.ts` 的 `ROUTES` 加 `'research'`；`App.tsx` 加 `lazy` + `case`；`nav.ts` 加 `NAV_ITEMS` 项（`category: 'ai'`，与 companion/content 同组，零新分类代码）与 `NAV_CATEGORY_MAP`；`i18n/*.json` 加 `nav.research.label/desc`。**约束 C6**。
- **约束**：C6（4 处同步）。
- **判定**：🟢 可实现 — 纯接线，4 处改动模式已固化，无新技术风险。
- **依赖 / 优先级**：无前置 / **P0**。

### F2 · 研究选题库与选题器
- **描述（儿童）**：进入后看到一列"研究主题"（如颜色、恐龙、太空、交通工具），点选即开始探索。（家长）可看到孩子偏好的主题分布。
- **范围**：in-scope：静态 `researchTopics.ts` 注册表（id / 标题 / 媒体类型 / 关联 Explore 组件 / 关联 AI 类型）+ 选题网格 UI。out-of-scope：动态从全网爬题。
- **所需逻辑**：新建 `src/data/researchTopics.ts`（复用现有 Explore 组件的主题与 `science` 主题）；选题 UI 仿 `ExploreMore.tsx` / `ContentStationPage` 的 tab 网格；选中后驱动 `ResearchModePage` 状态机。
- **约束**：C2（题库为静态 TS + 程序化，AI 仅生成讲解）；C4（若记录选题偏好需 Progress 字段）。
- **判定**：🟢 可实现 — 纯静态数据 + 既有网格组件仿写。
- **依赖 / 优先级**：F1 / **P0**。

### F3 · 互动探索沙盒（复用逐主题组件 vs 通用框架）
- **描述（儿童）**：选主题后进入"探索画布"——左侧媒体互动（如调色、看恐龙），右侧 AI 知识面板讲解，底部"记下我的发现"。（家长）可见孩子探索时长与发现数。
- **范围**：in-scope（推荐）：轻量 `ResearchCanvas` 编排壳 = 媒体槽（嵌入 `ColorExplore` 等）+ AI 知识面板槽（`useAiStream`）+ 发现采集槽。out-of-scope（不建议首期）：完全通用的"探索引擎"（任意主题自动生成交互）。
- **所需逻辑**：新建 `src/modules/research/ResearchCanvas.tsx`，以 `children`/插槽方式嵌入现有 Explore 组件；AI 面板复用 `useAiStream` 或 `generateContent`；媒体资源直接复用各 Explore 组件内置 emoji/图片。
- **约束**：C2（AI 讲解层）；C1（AI 面板须走安全链）。
- **判定**：🟡 受限 — **复用现有逐主题组件 + 轻量编排壳即刻可行（🟢）**；但建设"通用探索引擎"需前置抽象与大量主题接入（🔴），故整体定位黄；**强烈建议走复用路径**，避免支柱漂移（把探索做成第二个 drill）。
- **依赖 / 优先级**：F2 / **P1**。

### F4 · AI 研究内容生成（结构化 explainer 类型）
- **描述（儿童）**：探索中 AI 针对当前主题给出适龄讲解 / 趣味知识（如"为什么天空是蓝的"）。（家长）讲解可回看、可朗读。
- **范围**：in-scope（即时可用）：复用现有 `science` / `story` / `riddle` 三类 `generateContent` 作为研究知识来源。out-of-scope（需前置）：面向研究的**结构化 explainer**（如"主题→3 条知识点+1 个延伸问题"专属 JSON 形状）。
- **所需逻辑**：
  - 🟢 即时路径：调用 `generateContent('science'|'story', ageRange)`，仿 `ContentStationPage` 渲染。
  - 🔴 专属路径（前置）：`worker/index.mjs` 扩展 `CONTENT_TYPES` 加 `explainer`、新增 `CONTENT_PROMPTS.explainer`（强制 JSON）、过 `CONTENT_BLOCKLIST`、KV 前缀 `item:explainer:`；`contentClient.ts` 的 `AiContentType` 加 `explainer`；`ALLOWED_MODELS` 白名单复核。
- **约束**：C1（限速 chat 30/min、content 10s 冷却；须复用 `CHILD_SAFETY_PROMPT`/`INJECTION_PATTERNS`/`redactPII`）；C2。
- **判定**：🔴 需前置 — 结构化 explainer 必须**先扩展 Worker 端点 + 模型白名单复核 + KV 前缀 + 客户端类型**，属于明确前置工程；复用现有三类为 🟢 但有内容形态限制。
- **依赖 / 优先级**：`worker/index.mjs` 端点扩展 / **P1**（专属类型）｜**P0**（复用 science/story 即刻可用）。

### F5 · 知识卡片 / 发现画廊（KV 持久化）
- **描述（儿童）**：孩子在探索中"收藏"的 AI 知识、自己写的发现，汇成"我的发现画廊"，可回看、朗读、分享给家长。（家长）画廊即成长可见物。
- **范围**：in-scope：AI 生成知识卡片走 KV（复用 `/api/content/list` 通道）；**孩子自写发现**存 `Progress`（本地、离线优先）。out-of-scope：服务端账号体系。
- **所需逻辑**：画廊 UI 仿 `ContentStationPage` 列表 + `useStore` 新增 `discoveries` 字段（C4 登记于 `createInitialProgress()`）；AI 卡片复用 `listContent(type)` 拉取；缓存最近 N 条到 `safeStorage` 供离线（C5 协同）。
- **约束**：C4（Progress 字段登记）；C5（离线缓存）；C1（KV 内容已带安全过滤）。
- **判定**：🟢 可实现 — 画廊 UI 是 `ContentStationPage` 的仿写 + 本地 `Progress` 存储，无新机制。
- **依赖 / 优先级**：F3、F6 / **P1**。

### F6 · 研究笔记 / 标注
- **描述（儿童）**：对某个主题 / 知识卡片写一句话发现（如"我发现混合红+黄=橙"），可编辑、可删除。（家长）笔记是思维痕迹。
- **范围**：in-scope：键值笔记 `Record<topicId, string>`，复用 `poemNotes` 模式。out-of-scope：富文本 / 画图笔记。
- **所需逻辑**：`types.ts#Progress` 加 `researchNotes?: Record<string,string>`；`progress.ts#createInitialProgress()` 加 `researchNotes: {}`；`useStore` 加 `setResearchNote(id, text)`（仿 `setPoemNote`）；UI 复用 `Textarea` + `CandyButton`。
- **约束**：C4（字段登记）；组件禁硬编码中文（C 类，i18n）。
- **判定**：🟢 可实现 — 完全照搬 `poemNotes` 既有模式，零新架构。
- **依赖 / 优先级**：F1 / **P2**。

### F7 · 轻量理解测验（复用 RoundRunner）
- **描述（儿童）**：探索结束来 3–5 题小测验（如"恐龙住在哪里？"），答完给星、庆祝。（家长）测验成绩进掌握度。
- **范围**：in-scope：以 `RoundRunner` 承载，从研究题库 `makeQuestion` 出题。out-of-scope：把研究模式变成纯测验。
- **所需逻辑**：`ResearchModePage` 渲染 `<RoundRunner makeQuestion={...} difficulty={d} onRoundStart={()=>meta.syncNow()} onAnswered={...} onComplete={...} />`；`makeQuestion` 闭包从 `researchTopics` 的静态题或 `drill.ts#makeSpacedDrill` 抽题（~35% 复习叠加，复用现有）。
- **约束**：C3（`onRoundStart` 内 `meta.syncNow()` 锁存 DDA）；C2（题库静态/程序化）。
- **判定**：🟢 可实现 — RoundRunner/QuizCard 已完整，仅需出题闭包与接线。
- **依赖 / 优先级**：F2、F8 / **P0**。

### F8 · 自适应难度接入（DDA 锁存）
- **描述（儿童）**：测验难度随表现平滑升降，但**不会在做到一半时突然变难/变易**。（家长）难度曲线反映孩子状态。
- **范围**：in-scope：复用 `useAdaptiveDifficultyState`，测验段难度锁存。out-of-scope：探索媒体段做 DDA（探索不应被难度打断）。
- **所需逻辑**：`const [diff, setDiff, meta] = useAdaptiveDifficultyState('research')`；`RoundRunner` 的 `onRoundStart={() => meta.syncNow()}` 在**整轮开始**落档；`recordAttempt('research',{correct,ms,hintUsed,errorType})` 在 `onAnswered` 内调用驱动心流区（65–85%，>12s 或提示率>40% 或连 3 错降档）。
- **约束**：**C3（强制）— DDA 绝不可回合内重评，必须走 `onRoundStart` 落档点**，否则会像旧 `useState` 写法一样把孩子打回第 1 题。
- **判定**：🟢 可实现 — `useAdaptiveDifficultyState` 已解决锁存语义，按规约接线即可。
- **依赖 / 优先级**：F7 / **P0**。

### F9 · 进度与掌握度回写（practice → SRS）
- **描述（儿童）**：测验答对 → 该知识点掌握度提升、星星 +1；答错 → 温和降档、进复习。（家长）研究知识点出现在成长曲线。

### F12 · 离线 / PWA 兼容

## 5. 跨切面风险与缓解

| 风险 | 描述 | 缓解 |
|---|---|---|
| **R1 · AI 依赖与降级** | 研究模式核心体验（F3/F4/F5）依赖 AI 生成；Worker 限速（chat 30/min、content 10s 冷却）、KV 故障、模型截断都会断体验。 | 所有 AI 调用走 `useAiStream`/`useAiTask` 的 **`fallback` 静默降级**（孩子无感）；生成区按钮在冷却期 `disabled` 并显示倒计时（仿 `ContentStationPage`）；本地发现/笔记永远可用（F12）。 |
| **R2 · 儿童安全护栏** | 新端点/新交互若绕过既有防护链，可能输出不适内容或被注入越狱。 | **强制纪律（C1）**：任何研究 AI 调用复用 `CHILD_SAFETY_PROMPT`+`INJECTION_PATTERNS`+`CONTENT_BLOCKLIST`+`redactPII`+`ALLOWED_MODELS`；前端 `guardOutput` 二次校验；Code Review 把"是否复用防护链"作为合入门禁。 |
| **R3 · DDA 锁定被破坏** | 若研究测验段在 `RoundRunner` 内直接读 `recommendDifficulty` 而非锁存值，会回合内重评、把孩子打回第 1 题（比不自适应更糟）。 | **强制（C3）**：难度只经 `useAdaptiveDifficultyState` 锁存，`RoundRunner` 的 `onRoundStart={()=>meta.syncNow()}` 落档；Code Review 门禁检查"研究测验不得 render 期直接取推荐档"。 |
| **R4 · 存储合规** | 直写 `window.localStorage` 在 Safari 隐私/家长管控 WebView 抛 `SecurityError` 致白屏。 | **强制**：研究笔记/离线发现**必须**走 `safeStorage`（`safeGetJSON`/`safeSetJSON`），绝不直接 `localStorage`（C 类）。 |
| **R5 · 内容质量与适龄** | AI 生成知识可能超龄、事实偏差或重复。 | 端点侧 `CONTENT_PROMPTS` 强约束 JSON 形状 + 字数 + 适龄；`ageRange` 取自 `useProfilesStore`；前端对空/异常结果走 `fallback` 本地科普文案；可加"家长举报不合适"入口（复用 `ContentStationPage` 的报错位）。 |
| **R6 · 支柱漂移** | 把"研究/探索"做成了"第二个 drill"（刷题化），背离好奇心闭环定位。 | 设计纪律：测验段（F7）仅占轻量收尾（3–5 题、可选），主体必须是探索+发现沉淀；F3 优先**复用现有 Explore 组件**而非新建刷题引擎。 |
| **R7 · 进度字段漂移** | 新增 `Progress` 字段未登记 `createInitialProgress()`，老数据升级崩溃或徽章误判。 | 任何新字段同步改 `types.ts` + `progress.ts`（C4）；`resetAll`/`restoreProgress` 已用工厂，天然一致。 |
| **R8 · 奖励挤兑内在好奇（过度理由效应）** | 若奖励绑定"答对结果"而非"探索行为"，会触发过度理由效应（Lepper et al. 1973；Deci et al. 1999 元分析 128 实验，儿童更敏感），把内在好奇挤兑成外在动机，探索意愿反而下降。 | 徽章 / 奖励**绑定探索 / 发现行为**而非正确率（**F19**）；参考 R6 纪律，测验段仅占轻量收尾；上线以 A/B 验证奖励形态对探索时长的影响。 |
| **R9 · 认知超载（Explore）** | 5–10 岁一次呈现过多媒体 / 知识点会超出工作记忆（Sweller 2011），导致探索放弃、理解崩塌。 | Explore 信息密度上限 + 渐进揭示（**F18**，核心层→扩展层）；按 `ageRange` 取密度阈值，下端 5 岁更短媒体与更口语化文案。 |

## 6. 建议落地顺序

### MVP（P0，≈1–2 周，验证闭环 · 以 F17 闭环编排层为中枢）
- **F1** 模式入口与导航注册（4 处接线）
- **F2** 研究选题库与选题器（静态 `researchTopics.ts`）
- **F17** 研究闭环编排层（**中枢**）— 串 `Explore`（媒体槽）→ AI 知识卡（`generateContent`）→ `RoundRunner` 短提取测验 → `practice()`/SRS 巩固，单一状态机跑通 CMML
- **F7** 轻量理解测验（复用 `RoundRunner`/`QuizCard`）
- **F8** DDA 接入（锁存 + `onRoundStart` 落档）
- **F9** 进度回写（`practice()` → SRS，技能键 `research:<id>`）
- **F14** 儿童安全护栏（复用既有防护链，硬门槛）
- **F4（即时路径）** 复用 `science`/`story` 生成作为知识来源

> P0 目标：MVP 即以 **F17 闭环编排层**为中枢，验证"好奇心触发 → 多模态探索 → 短提取测验 → SRS 巩固"最小可玩闭环，安全、DDA 合规、进度落地。F17 是串起既有资产的核心新积木，缺失则四段体验互不连通。

### 阶段二（P1，扩展体验）
- **F18** 认知负荷护栏（信息密度渐进揭示，对应 G3）
- **F19** 内在动机保护（奖励探索行为而非结果，对应 G4 / 缓解 R8）
- **F3** 互动探索沙盒（轻量 `ResearchCanvas` 编排壳复用逐主题组件）
- **F5** 知识卡片 / 发现画廊（KV + 本地 `Progress`）
- **F11** TTS 集成
- **F13** 多语言（i18n 补键）
- **F15** 跨档案同步（复用既有桥接）
- **F4（专属 explainer）** 扩展 Worker 端点（🔴 前置完成后）

### 阶段三（P2，成长与留存）
- **F6** 研究笔记 / 标注
- **F10** 家长中心 / 成长博物馆视角（接入 `ParentPage`/`GrowthMuseumPage`）
- **F12** 离线 / PWA 兼容（预缓存清单同步）
- **F16** 徽章与激励体系（依赖 F6/F9 字段；行为型规则见 F19）
- **交错练习题序（G2）** — 作为后续优化项：在 `RoundRunner` 增加交错题序逻辑（与 SRS 协同），提升长时提取（阶段三之后排期）
