## 一、本轮性质

基于 R87 复验结论与 2026 竞品研究信号，**落地 E2「护眼模式 UI 开关」**。

R87 已确认：护眼**定时提醒**（E7）早已通过 `StudyGuard` + `studyClock` + `useSettingsStore.eyeCareMin` 真正可运行；但「**护眼模式主开关**」（一键暖色蓝光滤镜 + 降视觉密度）此前缺失。2026 横评中「古古识字」以「0 游戏纯学 + **蓝光过滤** + 定时休息」登顶，家长强诉求不伤眼——本栈 `reduced-motion` + `motion-density` 已提前布局，本轮补齐「可一键开启的完整护眼模式」，直击行业焦点。

## 二、改造内容（严格现有功能模块内，零逻辑返工）

| 文件 | 改动 | 说明 |
|---|---|---|
| `src/store/useSettingsStore.ts` | 新增 `eyeCareMode: boolean` + `setEyeCareMode(v)` + 初值 `false` | 护眼模式主开关状态，随设置持久化 |
| `src/styles/index.css` | 新增 `.eyecare-overlay` 暖色滤镜 + `[data-eyecare='on']` 激活规则 | `rgba(255,170,80,.10)` 暖橙滤镜吸收部分蓝光；`pointer-events:none` 绝不拦截交互；尊重 `prefers-reduced-motion`（P5）关闭过渡 |
| `src/App.tsx` | 根节点注入 `data-eyecare` + `data-motion="density-low"`，渲染 `<div className="eyecare-overlay" aria-hidden>` | 复用既有 `motion-density` 永动节流体系；开启时同步降视觉密度 |
| `src/modules/parent/ParentSettingsSection.tsx` | 家长中心新增「护眼模式」主开关（开/关）+ 说明文案 | 家长可控，与既有「护眼提醒间隔」并列协同 |
| `src/i18n/locales/zh-CN.json` | 新增 `parent.eyeCareMode` / `parent.eyeCareModeDesc` | 中文文案 |
| `src/i18n/locales/en-US.json` | 同步新增上述两键 | 满足 i18n 全量键对齐测试（否则死 key） |

**设计约束**：仅暖色叠加，不位移/缩放/模糊，保证内容清晰可读；叠加层 `z-index:80`、`pointer-events:none`，所有模态（如 `StudyGuard` z-90）仍清晰不被染色；与 `eyeCareMin` 定时提醒可同时生效。
