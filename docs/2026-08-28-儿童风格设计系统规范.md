# 儿童风格设计系统规范 v1

> 项目：宝贝学习乐园（React 19 + Vite + Tailwind v4 + Zustand）
> 调性：Soft Warm 柔和温暖 · 受众 3-8 岁（主力 4-6 岁）· 触屏优先 · 中文为主
> 说明：全部对比度已按 WCAG 相对亮度公式逐对验算，括号内为实测值。

## 1. 设计系统选型

基线借鉴：**Notion（Playful-Neutral 变体）+ Duolingo 式游戏化原则**，本项目**以定制为主、借鉴为辅**。

理由：

1. 帮帮识字/宝宝巴士的气质是「大圆角暖底 + 高饱和糖果色 + 图标即按钮」，71 套品牌库里没有现成儿童系统，Notion 的中性暖底与克制的圆角阶梯恰好是儿童风格的优质画布；
2. Duolingo 的「巨型 CTA + 按压位移 + 底部深色硬影」与现有 CandyButton 的果冻阴影机制天然同构，可直接移植其按压三态；
3. 参考品牌系统仅用于圆角/阴影/动效的尺度感，色彩与组件全部定制，保证 42 模块 tone 体系不被破坏。

## 2. 色彩令牌表（直接替换 tones.ts 与 candy-*）

机制不变：每色 main/deep/soft/on 四值，键名 pink/blue/yellow/green/purple/orange 不变。

**文字承载规则：main 上用深色 on 字，或 deep 上用白字**，全部 ≥4.5:1：

| tone | main | on（on-main） | deep（白字用） | soft |
|---|---|---|---|---|
| pink | #FF5C8A | #3D1424（5.40） | #C9285C（白5.33） | #FFE1EB |
| orange | #FF9F2E | #4A2B1F（6.19） | #B45F09（白4.58） | #FFF0DB |
| yellow | #FFC53D | #4A2B1F（8.03） | #8A5B00（白5.87） | #FFF6D9 |
| green | #3FC26B | #123B21（5.46） | #1B7A3D（白5.39） | #DFF5E7 |
| blue | #3D9BFF | #0C2D4F（4.87） | #0B5EC9（白6.07） | #DCEBFF |
| purple | #8F5BFF | #160830（4.60） | #5F2ECC（白7.64） | #EFE4FF |

**语义色**：成功 `#3FC26B` / 警告 `#FFC53D` / 错误 `#FF5C8A`（复用 pink main，避免引入第七色）/ 信息 `#3D9BFF`；均配各自 soft 底做浅色提示条。

**中性色**：
- 页面底 `--color-bg: #FFF8EF`（奶油暖白）
- 卡片 `#FFFFFF`
- 描边 `#F3E3CF`
- 正文墨色 `--color-ink: #4A2B1F`（暖棕，白卡上对比度 12.68）
- 次级文字 `#8A6F5C`

**渐变组合**：每色 main→deep 135°，仅用于 CTA 与大厅卡头图（如 `#FFC53D→#FF9F2E`）；页面顶部禁用大面积渐变，仅卡片级使用。

## 3. 字体与字号

**字体栈**：`'Baloo 2','PingFang SC','HarmonyOS Sans SC','MiSans','Microsoft YaHei UI',sans-serif`

- 拉丁数字走自托管 Baloo 2 圆体；中文无圆体可依赖，用字重补偿：标题/按钮 900（Black），正文 500，禁止 300 以下；
- 圆体感处理：标题与按钮文字统一 `-0.01em` 字距 + Baloo 2 数字混排 + 图标配字（FluffyIcon 惯例延续）；不做文字描边/阴影（防糊）。

**字号阶梯**（最小 17px，行高 1.4）：

| 层级 | 字号 |
|---|---|
| caption | 17px |
| body | 19px |
| card-title | 22px |
| section-title | 26px |
| page-title | 32px |
| hero-title | 44px |

4-6 岁界面正文一律 ≥19px。

## 4. 形状 / 阴影 / 间距 / 动效

**圆角**：
- `--radius-card: 24px`
- `--radius-btn: 9999px`（胶囊）
- `--radius-modal: 28px`
- 新增 `--radius-hero: 32px`（首页主任务区）

**间距阶梯**（4 基数）：8 / 12 / 16 / 24 / 32 / 48，新增 `--space-hub: 16px`（大厅卡间距）。

**果冻阴影规范**：
- 静置：`0 4px 0 {deep}`（底边硬影）+ `0 8px 16px rgba(74,43,31,.12)`
- 按压：`translateY(4px)` 且硬影归零（Duolingo 位移法）
- 悬浮元素：`0 12px 0 {deep}`

**动效**：
- 进场：240ms `cubic-bezier(.34,1.56,.64,1)`（过冲弹入）
- 按压：90ms `ease-out`
- 庆祝：600ms 弹跳 + 彩纸 1200ms 线性散落
- 反馈触发一律 ≤300ms（动画本身可长于 300ms，但首帧响应 ≤300ms）

## 5. 组件最小规格集

### 主 CTA（改造 CandyButton）
- ≥88×88px；结构 = FluffyIcon(32px) + 大字(22px/900)
- 三态：
  - 按压：下沉 4px + 音效
  - 成功：底色瞬变绿 + 对勾图标 + 上弹
  - 撤销：2 秒内边框变虚 + 「再按一次取消」文案（复用现有二次确认机制）

### HubCard（模块大厅卡）
- 正方形或 4:3；main→deep 渐变头图占卡面 60%
- FluffyIcon 56px 居中 + 卡名 22px/900
- 可选喇叭角标（点击朗读模块名）
- 卡间距 16px（`--space-hub`）

### 底部大导航
- 4-5 个 Tab，每 Tab 高 72px、图标 32px + 15px 文字
- 激活态 = main 色胶囊底 + 果冻上浮
- 固定在安全区以上

### 语音气泡 / 吉祥物
- 右下角固定吉祥物位 96px
- 气泡用 `--radius-modal` 圆角 + 尾巴，文字 ≥19px
- 出现时 240ms 弹入，同屏最多 1 个

### 庆祝反馈
- 星星/奖杯：中心 `scale 0.4→1.15→1` 弹入 + 旋转 ±8°
- 彩纸：六色 main 随机切片
- 全程 ≤1.6s 且可跳过

## 6. 页面级布局栅格

**首页「一屏一事」**：纵向三区——
1. 主任务区（`--radius-hero`，占视口高 ~55%，仅 1 个大 CTA + 吉祥物）
2. 3 个次要快捷位（等宽三卡，≤3 个）
3. 底部大导航

**模块大厅**：手机 2×2、平板 2×3 大卡网格，卡片宽 ≥160px。

**断点结论**：沿用 `lg=1024px` 不改；<lg 单列手机版式，≥lg 大厅 3 列、首页主任务区横排（吉祥物居右）。

**侧边栏**：32 项折叠为「全部」抽屉，首屏只露 5 个高频模块。
