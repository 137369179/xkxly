## 三、修复内容（最小、行为等价、不越权）

1. **Sidebar.tsx** — 将 `{/* Logo */}` 移出 `<aside>` 开标签（补 `>` 闭合标签），并删除错误且未使用的 `useLayoutEffect` 导入（保留 `motion`）。零逻辑改动。
2. **HanziPage.tsx（识字核心模块）** — 仅在调用点桥接类型：删除未使用的 `cachedLearnedCount` 解构；将
   `learnedMap={cachedLearnedMap}` 改为
   `learnedMap={Object.fromEntries(Object.entries(cachedLearnedMap).map(([k,v]) => [k, (v?.lv ?? 0) >= 1]))}`
   把 mastery 对象安全转为 `Record<string, boolean>`，与 `VirtualHanziGrid` 契约一致，且 `lv:0` 不再被误判为已学。**未触碰组件/Hook 内部逻辑，非重写。**
3. **ScreenTimePanel.tsx** — 删除未使用的 `useState` / `useEffect` 导入（保留 `useMemo`）。
4. **SciencePage.tsx（扩展模块，非三核心）** — 删除未使用的 `itemsByCategory` useMemo、`CATEGORY_META` 常量、`.map` 多余的 `i` 参数，并清理因此变为未用的 `useMemo` / `ScienceItem` 导入。
5. **nav.ts** — 将 `nursery` 图标由 `🎵` 改为 `🎶`，消除与 `songs` 的重复，恢复 `nav.test.ts` 唯一性断言。

**范围合规**：改动严格限定于修复上述回归，未引入任何新功能/无关模块；三核心模块仅做 1 行类型桥接 + 删未用变量，符合「禁止重复回写、优先重构既有逻辑」约束。改动未 `git commit`（依约定不主动提交）。
