# 儿童成语学习功能研究与规格说明书

> **项目**：宝贝学习乐园（Baby Learning Park）
> **模块范围**：成语故事屋（idioms）
> **文档类型**：研究与功能规格说明书（SRS）+ 开发建议方案
> **版本 / 日期**：v1.0 / 2026-08-20
> **目标用户**：6–12 岁儿童及其家长
> **关联能力基线**：65 成语、难度(1–3)+主题(勤学/智慧/自然/品格/寓言)双维分类、本地插画、读/学/AI讲故事/AI造句、自适应难度、SRS 记忆、跟读评测、家长反馈页

---

## 1. 绪论

### 1.1 研究背景
成语是中文学习的精粹，兼具语言学价值（凝练、修辞）与文化育人价值（历史典故、价值观）。对 6–12 岁儿童而言，成语的**记住**与**理解**之间存在显著断层：多数儿童能背诵成语，却难以在适切语境中使用，更难领悟背后的文化意象。本项目"成语故事屋"已具备基础的内容库与浏览/游戏能力，但对话式、情景化、记忆强化与家长闭环仍薄弱，亟需按儿童认知规律进行系统化升级。

### 1.2 研究目标
- 明确 6–12 岁儿童成语学习的认知基础、动机与兴趣特征；
- 对标市场成熟产品，识别差异化机会；
- 基于儿童学习规律，设计**分级适配、互动学习、记忆强化、家长闭环**四大类功能；
- 输出可落地、可度量的功能规格与分阶段研发方案。

### 1.3 研究/设计方法论
- 认知发展理论（皮亚杰 / 维果茨基 / 记忆巩固理论）；
- 学习科学（间隔重复 SRS / 提取练习 / 交错 / 迁移）；
- 游戏化设计（内在动机、心流、即时反馈）；
- 以本项目既有技术能力为约束的可行性分析。

## 2. 儿童认知发展与成语学习的契合分析

### 2.1 6–12 岁认知阶段特征（映射学习设计）
| 年龄段 | 认知特点（皮亚杰/概括） | 对成语学习的意义 | 功能设计启示 |
|---|---|---|---|
| 6–8 岁（前运算→具体运算期） | 具象思维为主，需实物/图像佐证；注意力短（约 15–20 分钟）；直观记忆强 | 成语抽象寓意难直接理解，需**图像+情境**桥接 | 情景动画、插画、跟读、单个成语义群短课 |
| 9–12 岁（具体运算→形式运算起步） | 逐渐能逻辑/部分抽象；好奇心与竞争意识强；开始理解反讽、比喻 | 可讲清"引申义/用法/感情色彩"，可做语境判别 | 语境选择题、成语接龙、造句迁移、归类对比 |

### 2.2 学习动机与兴趣偏好
- **内在动机**：发现感（"原来这个词有故事")、掌控感（进度、解锁）、好奇心；
- **外在动机**：积分/星星/徽章/段位（本项目已有 stars/medals/badges），需**即时、高频、低挫败**；
- **偏好**：卡通拟人、真人跟读、动效音效、可互动（点按/拖拽/说的出）、短回合小目标。

### 2.3 记忆科学依据
- **间隔重复（SRS）**：在遗忘临界点复习，优于集中式背记；本项目已具备 srs 能力，应复用于成语；
- **提取练习**：主动回忆（填空/判别）比重读记忆更牢固；
- **联想与情境编码**：故事→图像→自造句的多通路编码提升保持；
- **主动使用**：造句、讲述、迁移到真实场景是"学会"的标志。

> 推论：功能设计核心口诀 = **"看（图像/动画）→ 听懂（故事）→ 会读出（跟读）→ 能用（语境/造句）→ 记得住（SRS 巩固）→ 看得见（反馈/掌握）"**。

## 3. 市场现有儿童成语学习产品分析

> 说明：以下为**定性/结构式分析**（结合公开品类特征，非可核验的单一品牌流水数据）。落地前建议补充品牌级竞品测评（见 §8.4）。

### 3.1 主流产品形态
| 形态 | 代表类型 | 优点 | 常见不足 | 本项目机会 |
|---|---|---|---|---|
| 成语词典/阅读类 App | 成语查询、典故阅读、拼音释义 | 内容全、查询快 | 学完即走，无记忆闭环 | 已有丰富内容库，可补"学→练→测"闭环 |
| 试玩短视频/儿歌类 | 成语动画、带读 | 情境感、娱乐性强 | 难以检测掌握、无个性化 | 本项目可做**可交互情景 + 跟读评测**（已具备跟读） |
| 闯关答题/游戏类 | 看图猜成语、接龙、填空 | 反馈即时、有激励 | 重"猜对"轻"会用"，难度一刀切 | 新增**自适应难度 + 语境迁移**，避免"死记+碰巧" |
| 家长端/报告类 | 学习周报、掌握度、提醒 | 家长有掌控感 | 数据粗糙、不指导下一步 | 本项目家长页可升级**掌握度 + 针对建议** |

### 3.2 差异化机会
1. **"理解→会用→迁移"三级目标**而非只记释义（多数产品止步于"认识"）；
2. **个性化记忆节奏**：SRS + 自适应难度精准推送复习（多数产品用固定顺序）；
3. **儿童真实"会运用"的证据**：由跟读/造句/迁移题产生，而非仅正确率；
4. **家长可行动的反馈**：不止"学习 X 分钟"，而是"孩子在 ** 类成语上易混，建议这样练"。

## 4. 目标用户需求调研（框架与初步结论）

### 4.1 用户画像
- **P1 儿童-启蒙组（6–8）**：识字有限，注意力短，靠图和声音学习；家长主导选内容。
- **P2 儿童-自主组（9–12）**：能自主闯关、比较分数；有课本/考试适配诉求。
- **P3 家长-督导型**：关注学习量、掌握度、是否"会用"，愿接收针对性报告。
- **P4 老师/教研（延伸）**：按课堂主题（如"励志类成语"）布置、追踪班级掌握（远期）。

### 4.2 需求-痛点-机会表
| 需求 | 痛点 | 机会点 |
|---|---|---|
| 分级适合孩子 | 现按 1–3 级太粗，且不随能力变化 | 年龄段+自适应难度双层过滤 |
| 兴趣驱动 | 纯词典枯燥 | 游戏化闯关、情景故事、动画 |
| 记得住 | 学了就忘、无复习节奏 | SRS 间隔复习 + 联想记忆 |
| 会运用 | 会读不会用、遇语境懵 | 语境判别 + 造句 + 场景迁移 |
| 家长放心 | 看不到效果、无法干预 | 掌握度看板 + 报告 + 学习建议 |

### 4.3 调研方法建议（后续执行）
- 问卷（家长 200+）：学习时长、儿童兴趣点、易混成语、报告偏好；
- 轻量可用性测试（6–12 岁 5–8 名）：完成"学会一个全新成语"任务，记录完成率与情绪；
- 眼动/点击热区（可选）：观察看图猜成语时是否先看图后读题。

## 5. 功能概述与总体架构

### 5.1 设计目标
让每个 6–12 岁儿童都能按自己的节奏，把成语学到"**看得懂、读得响、记得牢、用得出**"。

### 5.2 总体架构（四层）
```
┌─ 儿童端 ─────────────────────────────┐
│  分级入口 · 游戏化闯关 · 情景故事 ·   │
│  动画演示 · 跟读 · 练习 · 间隔复习     │
├─ 能力与数据层 ──────────────────────┤
│  掌握度(每次语义单元) · 易混关系 ·    │
│  SRS 调度 · 自适应难度 · 熟练度画像   │
├─ 家长端 ─────────────────────────────┤
│  掌握度看板 · 周报 · 干预建议 · 目标   │
├─ 基建 ──────────────────────────────┤
│  内容库(65+) · 插画/动画 · TTS/ASR ·  │
│  AI(故事/造句/纠错) · 引擎(srs/difficulty) │
└──────────────────────────────────────┘
```

### 5.3 复用清单（基于本项目）
现有可直接复用：`IDIOMS + category/level`、`image`（本地 65 插画）、`initialProgress/mastery`、`srs`、`adaptiveDifficulty(levelMeta.syncNow)`、`quiz runner`、`speechEval(跟读)`、`useTtsStore/speak`、`AiPanel/AiTask`、家长模块（ReportExporter / StudyCharts / ParentAdvicePanel）。

## 6. 功能规格明细（含需求编号）

> 编号约定：FR=功能需求；NR=非功能；数据/实施见第 §7。

### 6.1 内容分级筛选与适配

| ID | 需求 | 优先级 | 说明 |
|---|---|---|---|
| FR-1.1 | 年龄段档位（6–8 / 9–12）过滤 | P1 | 在现难度(1–3)之上叠加"年龄段档位"，默认按档案年龄推荐 |
| FR-1.2 | 语义单元难度标签（识记/理解/运用） | P1 | 给每个成语标注需要的认知层级，指导练习类型 |
| FR-1.3 | 自适应难度联动 | P1 | 复用 `adaptiveDifficulty`：答对则适低压低、答错调整，个别化习题池 |
| FR-1.4 | 按主题/场景的单元包 | P2 | 如"勤学包""动物寓言包""写作用例包"，便于教师/家长布置 |
| FR-1.5 | 生词/熟词分流 | P2 | 首次接触标记"新学"，复习中的标记"巩固"，避免重复学已会 |

**验收**：同一儿童进入后，题池按 `age档 × level × mastery` 过滤；对 8 岁与 11 岁儿童呈现的默认题源可不同。

### 6.2 互动式学习模式（看→懂→用三阶）

| ID | 需求 | 优先级 | 说明 |
|---|---|---|---|
| FR-2.1 | 情景故事模式（沉浸读本） | P1 | 成语=一段含情节/对话的图文故事（本项目 story 已具备），末页点题"给我们的启发"（lesson 已具备） |
| FR-2.2 | 动画演示（字源/画面） | P1 | 关键成语配短动画（可先由插画 + 逐段配音 + 动效组成，降低制作成本） |
| FR-2.3 | 卡通角色讲解（AI 口吻） | P2 | 复用 AiStory/AiTask，以"小智"口吻讲清引申义、用法与感情色彩 |
| FR-2.4 | 跟读评测 | P1 | 复用 speechEval，读准成语/句子，即时给正确率鼓励 |
| FR-2.5 | 游戏化闯关（回合制） | P1 | 复用 quiz runner 做看图猜成语/释义题/首尾接力，连胜连胜星星 |
| FR-2.6 | 情景迁移小剧场 | P2 | 给出生活场景，让儿童从"用对成语"选项中选出合适项（做"会用"证据） |

**验收**：儿童可在"故事 / 动效 / 闯关"三种路径进入同一成语，并看到三种进度的统一掌握。

### 6.3 记忆强化机制

| ID | 需求 | 优先级 | 说明 |
|---|---|---|---|
| FR-3.1 | SRS 间隔复习 | P1 | 数据层记录每次语义条目学习/答对时间，按遗忘曲线排复习任务（复用 srs） |
| FR-3.2 | 联想记忆卡 | P2 | 成语↔图像↔造句↔英文/拼音联想，可做配对游戏 |
| FR-3.3 | 趣味练习矩阵 | P1 | 抽认卡、看图说话、缺字填空、语境判别、造句改写 |
| FR-3.4 | 易混辨析 | P2 | 识别高频易混对（如"守株待兔/坐井观天"），专门对比 |
| FR-3.5 | 主动提取（我不看提示靠回忆） | P2 | 复习优先"先回忆后看"；回忆失败才展示，减少被动重读 |

**验收**：对同一成语，间隔 N 天后的提取正确率在触摸目标（如 ≥70%）可度量（见 §8）。

### 6.4 家长监督与学习反馈系统

| ID | 需求 | 优先级 | 说明 |
|---|---|---|---|
| FR-4.1 | 掌握度看板 | P1 | 按成语/主题/难度展示掌握度（复用 progress/mastery 投影） |
| FR-4.2 | 学习报告（周报/月报） | P1 | 复用 ReportExporter / StudyCharts：学习量、掌握度变化、易混项、用时 |
| FR-4.3 | 针对建议 | P1 | ParentAdvicePanel 升级：如"孩子在'比喻类'理解偏弱，建议做 3 次语境判别题并复习 X、Y" |
| FR-4.4 | 家长目标设置 | P2 | 家长设定"每周掌握 5 个新成语 + 复习 10 个"，儿童端显示进度 |
| FR-4.5 | 儿童自主目标 | P2 | 儿童自定"我今天想学 3 个"、解锁徽章激励 |

**验收**：家长每周收到一份含"掌握提升 + 易混点 + 建议动作"的可执行报告。

### 6.5 为非功能需求
| ID | 需求 | 说明 |
|---|---|---|
| NR-1 | 隐私与儿童保护 | 最小化采集、家长可导出/删除、无第三方投放 |
| NR-2 | 无障碍 & 安全性 | 屏幕朗读、更大点击热区、无外链、发音标准 |
| NR-3 | 性能 | 内容与图片本地化、复习调度低延迟 |

## 7. 功能原型设计（信息架构与关键流程）

### 7.1 信息架构（儿童端）
```
成语首页（库/闯关/复习/我的成就）
 ├ 分级入口：年龄段档 × 主题 × 难度
 ├ 闯关地图：单元 → 关卡 → Boss（含 BossTimerBar 式倒计时鼓励）
 ├ 学习详情：大图/动画 + 故事 + 跟读 + 道理 + 相关扩展
 ├ 复习中心：SRS 今日任务 + 易混辨析
 └ 成就：回合星星 / 成语徽章 / 连对流水
```

### 7.2 关键交互流程
```
新成语进入  → 看动画/大图 → 听故事 → 跟读(评测) → 道理点题
           → 闯关题(自适应) → 正确→输出星星/mastery
           → 结束进入复习队列(SRS)
家长查看     → 周报 → 易混/薄弱 → 建议动作 → 一键布置复习任务
```

### 7.3 界面示意（文字线框）
- **卡片（复用 IdiomArt）**：上插画，下 pid/拼音 + 主题徽章 + 难度点，右滑查看"已掌握"角标；
- **闯关**：上半题干（题干/图/发音），下半 A/B/C/D 大按钮，答对即时反馈+星星动画；
- **跟读**：复用一个词条的卡拉OK式高亮 + 评分环；
- **家长报告**：卡片式图表 + "建议下一步"。

## 8. 教育效果评估设计

### 8.1 指标体系（三层）
| 层级 | 指标 | 数据来源 |
|---|---|---|
| 行为 | 学习时长/频次/完成单元数/复习完成率 | 埋点 |
| 掌握 | 按语义单元的正确率、SRS 间隔后提取正确率、跟读通过率 | 各练习/评测 |
| 运用 | 语境迁移题正确率、自造句质量(可经人工/AI 打分)| 题型/AI |

### 8.2 评估方法
- **前测-后测**：固定一组"目标成语"，学前测掌握、学后 1 天/7 天/30 天随访提取，看保持曲线；
- **对照设计（A/B）**：同年龄段随机分"组件成语组 vs 基础成语组"，7 天后测迁移正确率；
- **对比基线**：以"不看提示回忆正确率"为金指标，目标 ≥70% 于 30 天后。

### 8.3 抽样与伦理
- 6–12 岁各班型 6–8 名体验组 + 规模化问卷家长 200+；
- 遵循儿童研究伦理：家长知情同意、可随时退出、数据脱敏。

### 8.4 竞品测评补充
- 对 §3 中的代表性产品各做一次 3 维评估（分级/互动/记忆/家长反馈），输出矩阵，作为功能取舍依据。

## 10. 开发建议方案与路线图（分阶段）

| 阶段 | 周期 | 交付 | 里程碑验收 |
|---|---|---|---|
| P0 需求/内容 | 短 | 竞品矩阵、家长问卷、年龄档与语义标签规则、易混表 | 设计评审通过 |
| P1 核心闭环 | 中 | 分级过滤、情景故事、跟读、闯关(自适应)、SRS 复习、家长周报 | 儿童可"学→练→复习→报告"走通，指标可采集 |
| P2 深化 | 中 | 动画演示、联想卡、易混辨析、语境迁移题、家长目标 | 记忆曲线提升可测；迁移正确率上升 |
| P3 规模化/评测 | 长 | 对照实验数据、调参、绩效证明 | 出具效果评估报告 |

**风险与对策**：制作成本高(动画)→插画+配音+轻动效逐步替代；陌生术语多→字源/图像桥接；家长顾虑→隐私可控+报告可解释。

## 11. 结论
基于儿童认知发展、记忆科学与市场对标，本项目具备在"成语故事屋"上实现"分级适配 + 互动学习 + 记忆强化 + 家长闭环"四大能力的成熟条件。建议按 **P1 核心闭环 → P2 深化 → P3 评测**路线推进，核心立足点是用**可提取、可迁移、能解释（给家长）**的专业能力，与现有"认成语"类产品拉开差距。
