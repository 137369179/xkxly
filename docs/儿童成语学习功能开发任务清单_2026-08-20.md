## 0. 前置（数据与内容基线）

### T-0.1 为成语补充「年龄段档位」字段
- **关联**：FR-1.1
- **涉及**：`src/data/idioms.ts`、消费端（`IdiomsPage`）
- **要点**：在 `Idiom` 接口增加 `ageBand: 6to8 | 9to12`（或 `minAge: 6|7|8|9`），为 65 条成语标注；保留既有 `level`。
- **验收**：
  - 类型检查通过（`tsc -b`）；65 条均含 `ageBand`，无缺省；
  - 可 `getIdiomsByAge(band)` 返回对应集合，各档非空且两档存在差异。

### T-0.2 语义难度标签（识记/理解/运用）
- **关联**：FR-1.2
- **涉及**：`src/data/idioms.ts`、类型 `Idiom`
- **要点**：新增 `semanticLevel: 'recognize'|'comprehend'|'apply'`（识记/理解/运用），为成语标注。
- **验收**：65 条均有合法标签；渲染可据此映射练习类型提示。

### T-0.3 易混关系数据
- **关联**：FR-3.4（易混辨析）
- **涉及**：新增 `src/data/idiomRelated.ts`（`relatedMeta`）
- **要点**：建立「成语 id ↔ 配图/联想 ↔ 易混对」静态表，如 `守株待兔`↔`坐井观天`。
- **验收**：每对易混双向可达；饮用数据不破坏既有 `IDIOMS` 校验。

## 一、内容分级筛选与适配

### T-1.1 年龄段档位联动过滤
- **关联**：FR-1.1 / FR-1.3
- **涉及**：`src/modules/idioms/IdiomsPage.tsx`、`src/store/adaptiveDifficulty.ts`、`src/profile`（年龄档案，若有）
- **要点**：筛选条件 = `年龄档 ∩ 难度level ∩ 主题category`；无年龄档案时降级为仅 level。
- **验收**：
  - 设 8 岁档案时，列表绝不出现 `ageBand=9to12` 成语；11 岁档同理不出现 6–8 专属；
  - 切档后列表重算且猜成语题池同步跟随（不越档）；
  - 无档案时行为与现状一致（仅 level）。

### T-1.2 生词/熟词分流标记
- **关联**：FR-1.5
- **涉及**：`src/store/useStore.ts`（mastery 投影）、`IdiomsPage` 卡片
- **要点**：对已 `mastery` 成语标「已掌握」，新学标「新学」，复习中属「巩固」。
- **验收**：卡片出现状态角标；已掌握成语不重复进入"新学教程"。

### T-1.3 主题单元包
- **关联**：FR-1.4
- **涉及**：`IdiomsPage`、`src/data/idioms.ts`
- **要点**：按现有 category 聚合为"单元包"入口（勤学包/动物寓言包/写作用例包）。
- **验收**：点击单元包只展示该 category 成语；提供数量统计。

## 二、互动式学习模式（看→懂→用）

### T-2.1 情景故事模式
- **关联**：FR-2.1
- **涉及**：`IdiomsPage` 的 `IdiomDetail`、`story`/`lesson` 字段
- **要点**：将详情页改为"分页读本"：大图/动画 → 故事逐段 → 点题"小道理"；保留 AI 故事。
- **验收**：单成语可经读本完整走完 ≥3 步；末页呈现 `lesson`；读本步骤可前进/后退。

### T-2.2 插画 + 配音的轻动画演示
- **关联**：FR-2.2
- **涉及**：`IdiomArt`/`motion`、`speak`
- **要点**：图渐显/逐段文字 + 逐句 TTS 配音的高亮朗读（低制作成本动效替代真动画）。
- **验收**：动画逐句高亮与 `speak` 音频节奏对齐；暂停/重播可用；无音频时仍可阅读。

### T-2.3 AI 角色讲解（口吻化）
- **关联**：FR-2.3
- **涉及**：`AiPanel`/`AiTask`/`useAi`、guardian
- **要点**：以"小智"口吻讲清引申义/用法/感情色彩，复用 `idiomStoryTask` 并加防护。
- **验收**：输入命中护栏时给出友好回退；输出为单成语限定，不越界。

### T-2.4 跟读评测集成
- **关联**：FR-2.4
- **涉及**：`src/components/feedback/SpeechEvalButton`（或 `FollowRead`）
- **要点**：详情页加"跟读"入口，记录跟读通过/得分进入掌握数据。
- **验收**：能读成语与例句；通过后打卡一次该成语的"朗读"掌握单元；不支持语音时优雅降级。

### T-2.5 游戏化闯关（回合制，自适应）
- **关联**：FR-2.5
- **涉及**：`QuizSessionRunner`、`useAdaptiveDifficultyState`
- **要点**：猜成语/释义题复用现有 runner；**题干取自当前年龄档+level 池**；胜出给星星/连对。
- **验收**：8 岁档不出越档题；答对可 `learnSkill(idom:id)` 标掌握；连胜流程与结算正常。

### T-2.6 语境迁移动剧场（会用）
- **关联**：FR-2.6
- **涉及**：新增题型或复用 `QuizCard`/`smart-practice`
- **要点**：给出生活场景，选"用对成语"项；计为"运用"掌握证据。
- **验收**：一题一场景、选项含一正确成语与干扰项；答对后该成语运用掌握 +1；结果可进入家长报告。

## 三、记忆强化机制

### T-3.1 语义单元级掌握记录
- **关联**：FR-3.1
- **涉及**：`src/store/useStore.ts`、`src/lib/srs.ts`
- **要点**：把掌握/复习记录落到成语(或成语-语义)粒度，接入 srs 调度。
- **验收**：对成语的学习/答对/复习事件写入；`srs` 可按遗忘曲线产生"待复习"列表。

### T-3.2 SRS 复习中心
- **关联**：FR-3.1 / FR-3.5
- **涉及**：新增 `IdiomReviewCenter`（可置于 idioms 目录）、`useMastery` 细粒度订阅
- **要点**：展示"今日需复习"任务；优先"先回忆后看"（不直接给答案）。
- **验收**：复习列表按 srs 计算且可完成；完成后状态回写；空任务时优雅提示。

### T-3.3 联想记忆/趣味练习矩阵
- **关联**：FR-3.2 / FR-3.3
- **涉及**：`data/idiomRelated.ts`、`QuizCard`
- **要点**：抽认卡/配对/缺字填空/语境判别/造句任务切换。
- **验收**：≥4 种题型可进入；每种题型有分数与即时反馈，不影响已有 quiz runner。

### T-3.4 易混辨析
- **关联**：FR-3.4
- **涉及**：`data/idiomRelated.ts`、练习页
- **要点**：对易混对出"对比题"，引导区分（如意义/情感色彩/用法）。
- **验收**：易混对可进入对比练习；答对有解释提示；不与其他练习冲突。

### T-3.5 主动提取优先（无提示回忆）
- **关联**：FR-3.5
- **涉及**：复习组件
- **要点**：复习默认先呈现含义请回忆词形/出的用法；回忆失败才展示。
- **验收**：交互顺序（先回忆后揭示）达标；记录"未提示回忆正确率"供评估。

## 四、家长监督与学习反馈

### T-4.1 掌握度看板（成语维度）
- **关联**：FR-4.1
- **涉及**：家长模块、`useStore` mastery 投影
- **要点**：按成语/主题/难度聚合掌握度可视化（可复刻 StudyCharts 风格）。
- **验收**：图表按语义单元/主题展示掌握占比；数据随学习实时更新。

### T-4.2 周/月报告
- **关联**：FR-4.2
- **涉及**：`src/components/study/ReportExporter`、`StudyCharts`
- **要点**：学习量、掌握度变化、易混项、用时。
- **验收**：可生成周报且字段齐全；导出/预览可用（沿用现有导出）。

### T-4.3 针对性建议
- **关联**：FR-4.3
- **涉及**：`src/components/study/ParentAdvicePanel`
- **要点**：基于薄弱语义类型给出"建议做 N 次 XX 练习并复习 X、Y"。
- **验收**：对"比喻类偏弱"样本给出可执行建议；建议含具体成语与练习类型。

### T-4.4 家长目标设置
- **关联**：FR-4.4
- **涉及**：家长设置 + 儿童端目标任务
- **要点**：家长设"每周新学 5 + 复习 10"，儿童端显示进度。
- **验收**：目标可设置并持久化；儿童端进度条随学习更新；达成有提示。

### T-4.5 儿童自主目标与徽章
- **关联**：FR-4.5
- **涉及**：成就/徽章模块（badges）
- **要点**：儿童自定"今日学 3 个"，完成解锁徽章。
- **验收**：自定目标可建/可改；完成触发徽章；数据持久化。

## 五、非功能与基建

### T-5.1 隐私与儿童保护
- **关联**：NR-1
- **涉及**：采集点、家长设置
- **要点**：最小化采集；家长可导出/删除；无第三方投放。
- **验收**：新增采集点均在设置页声明；导出/删除功能可操作。

### T-5.2 无障碍与安全
- **关联**：NR-2
- **涉及**：组件
- **要点**：屏幕朗读标签、更大热区、无外链、发音标准。
- **验收**：关键操作具 aria-label；热区 ≥ 44px；不含外部链接。

### T-5.3 性能与本地化
- **关联**：NR-3
- **涉及**：构建、资源
- **要点**：内容/图片本地化；复习调度低延迟。
- **验收**：`npm run build` 通过；成语资源不依赖外部 URL；无阻塞首屏大图（引用本地 640px 插画）。
