## 0. 视觉真相源与硬约束（先读）

研究模式**不新建设计系统**，直接复用现有糖果毛绒系统（`@theme`）。任何新资产必须落在以下边界内：

| 真相源 | 取值 | 用途裁定 |
|---|---|---|
| `--color-ink #4a3b4e` | on cream `#fff5f8` = **9.70:1** | 正文默认；soft 变体字色（修法，A-2 提升到 8.50–9.38:1） |
| `--color-ink-soft #8a7791` | on cream = **3.84:1** | ⚠️ 仅 ≥24px 大文本；**禁作正文**（G2） |
| `--color-cream #fff5f8` | 背景基线 | 正文/卡片底色 |
| candy-* 六主色 | `candy-pink #ff75a0` / `candy-blue #70d6ff` / `candy-yellow #ffd166` / `candy-green #6EE7B7` / `candy-purple #c4b5fd` / `candy-orange #ff9f5a` | **仅背景与装饰**；浅糖果色 on 白 1.35–2.53:1，禁承载文字（§5.3-3） |
| candy-*-deep | `candy-pink-deep #e83e8c`(3.58) / `candy-purple-deep #8b5cf6`(4.23) / `candy-yellow-deep #e5a516`(2.02❌) | 仅大文本；`candy-purple-deep` 可作焦点环（4.5:1） |
| `TONE_STYLE[tone].on` | 现状 5/6 个 solid 用 `#FFFFFF` 白字，对比度 **1.83–2.72:1 ❌** | **禁止沿用**（G1 红线） |

> 🔴 **最关键的 1 条视觉硬约束（G1，合入门禁）**：研究模式内**任何**承载文字的 solid 按钮 / 标签 / 知识卡 / 主题卡，**不得**用 `TONE_STYLE[tone].on = '#FFFFFF'`，也不得用 soft 变体的 `deep` 字色；**solid 一律 `--color-ink #4a3b4e` 深字 + `size="lg"`（≥20px bold 落 WCAG 大文本档），soft 一律 `ink` 字色**（实测由 1.83–3.94:1 提升至 3.81–9.38:1）。yellow 是唯一已用深字的色调（`on='#5A4408'`, 6.04:1），可作为合规范本。

## 3. 动效资产规格

> 全部时长区间来自可访问性文档 §4.4；错误反馈禁 shake/禁红来自 §4.4 与 **S8 / F19**；减少动效来自 **B9 / G7**（沿用 `index.css:303` 全局降级 + `celebrate.ts:107` 的 `matchMedia` 判定，**研究模式 JS 动画不得绕过**）。

| 类型 | 时长 | 映射（`@theme`） | 备注 / 门禁 |
|---|---|---|---|
| 微反馈（点击 / 按压） | **150–300ms** | `--animate-squishy 0.3s` ✅ | 默认 300ms；上限即 300ms（G11） |
| 元素入场 | **300–450ms** | `--animate-pop-in 0.42s` ✅ | 超 450ms 显迟滞（G11） |
| 层间转场 / 渐进揭示 | **250–400ms** | 新增，缓动 `cubic-bezier(0.34,1.56,0.64,1)` | 弹性可保留，勿超 400ms |
| 折叠收起（扩展层回收） | **≤300ms** | — | 收起快于展开；不位移核心层锚点（F18 §4.3-6） |
| 奖励庆祝 | **≤1200ms 且可跳过** | `celebrate.ts` 现有 | 已读 `prefers-reduced-motion`，须沿用（G7/G11） |
| 循环 / 呼吸类 | 周期 ≥1.6s，幅度 ≤10px | `float 4s`/`twinkle 1.8s`/`bounce-soft 1.6s` | **探索段 ≤1 处，测验段 0 处**（F18 §4.1，Mayer 连贯性） |
| 错误反馈 | 150–300ms，**禁 shake** | ~~`--animate-shake 0.45s`~~ | F19：抖动+红=惩罚信号；改用 `squishy` + 中性色 +「再想想」（S8/G11） |

**硬禁止（B8/G18）**：>3Hz 闪烁；>25% 视口明暗跳变；视差滚动；自动播放且不可暂停的动效。
**动效并发**：同屏并发循环动画 5–7 岁 ≤1、8–10 岁 ≤1、**测验段恒为 0**（G11/S14）。

## 4. 色盲安全 token

### 4.1 对 / 错反馈「四重冗余」配色 token（禁止粉 vs 绿）

> 依据：可访问性文档 §5.3、附录 A-3（`green #5FD68B` vs `pink #FF6FA5` deutan 下仅 **1.19:1**，绝对禁止用于对错）。改用 **蓝 = 对 / 橙 = 待改进**。

| 冗余层 | 对（correct） | 待改进（needs-improvement） |
|---|---|---|
| ① 颜色 | 蓝 `#4FC3F7`（主）/ 蓝深 `#2196C9` | 橙 `#FF9F5A`（主）/ 橙深 `#E0742B` |
| ② 图标（≥24px，1.5px 描边） | ✓（`#2196C9` 描边） | ○（`#E0742B` 描边，空心圆） |
| ③ 文案 | 「对啦」 | 「再想想」 |
| ④ 位置 | 固定反馈槽（如卡片右上角），不随内容位移 | 同槽位 |

**建议落地的 CSS 变量（供 dev 直接引用）：**
```css
--rm-correct:      #4FC3F7;  --rm-correct-deep: #2196C9;  --rm-correct-bg: #DDF2FD;
--rm-improve:      #FF9F5A;  --rm-improve-deep: #E0742B;  --rm-improve-bg: #FFEBDB;
--rm-icon-check:   #2196C9;  /* ✓ 描边 */
--rm-icon-circle:  #E0742B;  /* ○ 描边 */
```
> 文本对比说明：反馈标签字用 `deep` 色（`#2196C9`/`#E0742B`）须以 `size="lg"`（≥20px bold = WCAG 大文本）渲染才达 ≥3:1；**若反馈文案需落到正文尺寸，则回退 `ink #4a3b4e`**（9.7:1）。`blue.deep`/`orange.deep` 属「仅大文本」档（参考 A-4 同档 4.23:1），不得用于小字。

## 6. 插画密度规范（引用 F18 §4.2）

> 图占面积 55–70%，文字 ≤30%，留白 ≥15%（核心层）；文字是「图的注解」非主体。

| 指标 | 5–7 岁 | 8–10 岁 | 依据 / 门禁 |
|---|:--:|:--:|---|
| 单屏插画数量（核心层） | **1–2** | **≤3** | Mayer 连贯性；F18 §4.1 单屏视觉元素 ≤3/≤5 |
| 图占面积比例 | **60–70%** | **55–65%** | F18 §4.2（55–70%） |
| 文字占面积 | **≤25%** | **≤30%** | 文字为注解 |
| 留白比例 | **≥15%** | **≥15%** | 防拥挤 |
| 核心层概念数 | **1** | **≤2** | F18 §4.1 |
| 单屏视觉元素（含可交互） | **≤3** | **≤5** | F18 §4.1（G9） |
| 说明文字与图间距 | **≤16px** | **≤16px** | 空间邻近（Mayer） |
| 阅读行长 | 中文 ≤16 字/行 | 中文 ≤16 字/行 | F18 §4.2 |
| 单句/总字数 | ≤12 / ≤40 | ≤18 / ≤80 | F18 §4.1（G9） |
| 背景装饰 | ≤3，opacity ≤20% | ≤5，opacity ≤25% | F18 §4.1（G20） |

**执法**：阈值写入 `researchTopics.ts` 的 `density`（`ageRange` 取档），DEV 超限 `console.warn`（不阻断生产），并进 §7 门禁 G9 人工抽检。

## 7. 交付与验收门禁（美术自检表）

> 每项资产交付时按对应门禁逐条自检；未过项在交付备注显式标注偏离理由（参照可访问性文档 §6 门控清单）。

| 门禁 | 档位 | 含义 | 关联资产 |
|---|---|---|---|
| **G1** | Basic（红线） | solid 禁白字 → `ink` 深字 + `size lg`；soft 改 `ink` 字 | A,B,C,F,G,K,M（全部承载文字的资产） |
| G2 | Basic | 正文不用 `ink-soft` | 所有文本资产 |
| G3 | Basic | 触控目标：CTA ≥64px，选项 ≥56px，图标 ≥44px | M；C 图标；K |
| **G4** | Standard | 对/错四重冗余（灰度+deutan 仍可辨） | K；F；G |
| G5 | Basic | 无语音也能懂（关 sound 走完闭环） | F；H；I |
| G6 | Basic | 无声画也能读（视觉演示有文字等价） | F；D/E 插画 |
| G7 | Basic | 减少动效（reduced-motion 后无循环/粒子） | L；D/E 循环装饰 |
| **G8** | Comprehensive 前置 | 字号 token 化（禁 `text-[Npx]`，用 rem） | 全部（C1 前置） |
| G9 | Standard | 信息密度上限（两年龄档各抽 3 主题计数） | B,C,F；§6 全部 |

| G11 | Standard | 动画时长（无 >450ms 入场 / >1200ms 庆祝 / 错误 shake） | L；K（错误）；§3 全部 |
| G12 | Standard | 无时间压力（禁倒计时 UI） | 全部（无倒计时资产） |
| G13 | Basic | 焦点可见（键盘 Tab 全闭环焦点环 ≥3:1） | M |
| G14 | Standard | 加载/降级不留白（骨架屏 + 文案） | J；I |
| G15 | Standard | 流式内容 aria-live | F（AI 讲解容器） |
| G16 | Standard | i18n 不截断（en-US 长 30–60% 预留） | A,B,C 标签；F 文本 |
