## 0. 结论速览

| 项 | 结论 |
|---|---|
| **MVP（P0）目标档** | **Basic 全量必达**（红线，不达标不允许合入） |
| **随 F18/F19 上线（P1）目标档** | **Standard 全量必达**（研究模式的正式验收线） |
| **阶段三（P2）目标档** | **Comprehensive**（家长中心承载自定义项） |
| **最严重的既存缺陷** | 现有 `TONE_STYLE` 六个色调中 **5 个 solid 按钮用白字，实测对比度仅 1.83–2.72:1**，全部低于 WCAG 大文本 3:1 底线；`soft` 变体（deep 字 on soft 底）2.18–3.94:1 同样普遍不合规 |
| **最严重的多模态风险** | `pink` 与 `green` 在红绿色盲（deuteranopia）模拟下对比度仅 **1.19:1**——若对/错反馈靠"粉/绿"区分，对色盲儿童等于**没有反馈** |
| **给开发的 1 条硬性约束** | 研究模式内**任何**承载文字的 `CandyButton` / 标签 / 知识卡不得沿用 `TONE_STYLE[tone].on = '#FFFFFF'` 与 soft 变体的 `deep` 字色：**solid 用 `--color-ink #4a3b4e` 深字 + `size="lg"`（≥20px bold），soft 用 `ink` 字色**（实测由 1.83–3.94:1 提升至 3.81–9.38:1）。此项为合入门禁，逐组件核对 |

## 1. 目标用户画像（5–10 岁）

研究模式面向 5–10 岁跨度极大的认知区间，**必须按两段分别取阈值**，不能用同一套密度与节奏。

### 1.1 5–7 岁段（学前 / 一二年级）

| 维度 | 能力假设 | 依据类型 |
|---|---|---|
| 阅读 | 识字量 ≤300–800 字，**不能独立读完一段说明文**；依赖图形 + 朗读 | 【文献支撑】识字发展常规区间 |
| 工作记忆 | 同时保持 **2–3 个信息块**（成人 4±1，Cowan 2001；学前显著更低） | 【推断】具体块数需 A/B 验证 → 见附录 B-1 |
| 持续注意 | 单一活动 **5–8 分钟**，之后需换模态或换任务 | 【推断】需埋点验证 → B-2 |
| 精细动作 | 指尖触点直径大、落点偏移大；**拖拽与长按易失败**，点击最可靠 | 【文献支撑】幼儿触屏研究一致结论 |
| 抽象能力 | 需要**具体形象**（图 + 实物类比）绕过抽象语言门槛（Paivio 双重编码） | 【文献支撑】 |
| 错误反应 | 对红色 / 震动 / 音效突变**易产生焦虑与放弃** | 【推断】需家长问卷 → B-3 |

**视觉后果**：核心层 1 个概念；朗读为默认开启；主操作按钮 ≥64px；不使用拖拽作为唯一交互；文字仅作"图的注解"而非信息主体。

### 1.2 8–10 岁段（三四年级）

| 维度 | 能力假设 | 依据类型 |
|---|---|---|
| 阅读 | 可独立读 2–3 句短句，**可承担"读—做"型任务**，但长段落仍会跳读 | 【推断】需 A/B → B-4 |
| 工作记忆 | 同时保持 **3–4 个信息块** | 【推断】→ B-1 |
| 持续注意 | 单一活动 **8–15 分钟** | 【推断】→ B-2 |
| 精细动作 | 拖拽可用；可接受二级菜单与多步操作 | 【文献支撑】 |
| 动机 | 已对"被当小孩子对待"敏感；奖励语气需**平实肯定**而非过度卖萌 | 【推断】需 A/B → B-5 |

**视觉后果**：核心层 ≤2 个概念；朗读可默认关闭但**入口必须显眼**；允许扩展层深至 3 层；文案去"叠词化"。

> ⚠️ 上表中标注【推断】的 6 项**不得当作既定事实写进代码常量后就不再回看**。全部收敛到附录 B 的假设清单，由埋点 / A/B 验证后再固化阈值。

## 2. 三级可访问性分级

分级是**累进**的：Standard 包含 Basic 全部，Comprehensive 包含 Standard 全部。

### 2.1 Basic —— 最低合规（红线，P0 必达）

> 定义：**低于此档即视为缺陷，禁止合入。** 目标是"任何孩子都不会因为看不清、点不到、听不见而无法完成闭环"。

| # | 条目 | 量化门槛 |
|---|---|---|
| B1 | 正文文本对比度 | ≥ **4.5:1**（正文取 `--color-ink #4a3b4e` on `--color-cream #fff5f8` = **9.7:1** ✅） |
| B2 | 大文本 / 按钮文字对比度 | ≥ **3:1**，且字号须真正落入 WCAG 大文本定义（**≥24px 常规 或 ≥18.66px 粗体**） |
| B3 | 触控目标 | ≥ **44×44px**（复用既有 `@utility min-touch-target` 与 `CandyButton size="sm"`）；相邻目标间距 ≥ **8px** |
| B4 | 色彩非唯一载体 | 对 / 错 / 已选 / 可点 状态**必须**同时有非颜色线索（图标或文字或形状），WCAG 1.4.1 |
| B5 | TTS 基础可用 | 每张知识卡、每条 AI 讲解都有**显式朗读按钮**（≥44px）+ 全局停止入口；朗读失败/不支持时给**可见提示**而非静默 |
| B6 | 视觉文本等价 | **TTS 永不作为唯一信息通道**——任何朗读内容必须有同义可见文本（WCAG 1.1.1 精神） |
| B7 | 焦点可见 | 键盘 / 外接开关聚焦时有 ≥3:1 可见焦点环（建议 `#7B57E8` on cream = **4.5:1** ✅，2px 实线 + 2px 偏移） |
| B8 | 光敏安全 | 无 >3 次/秒 的闪烁或大面积明暗跳变（WCAG 2.3.1） |
| B9 | 系统减少动效 | 尊重 `prefers-reduced-motion: reduce`（`src/styles/index.css:303` 已有全局降级，**研究模式新增动画不得用 JS 内联绕过它**） |
| B10 | 非文本对比 | 图标、进度条、卡片边界与背景对比 ≥ **3:1**（WCAG 1.4.11） |

### 2.2 Standard —— 良好体验（P1 正式验收线）

> 定义：孩子能**自主、低焦虑地**跑完好奇心闭环，且家长不必在旁解释。

| # | 条目 | 量化门槛 |
|---|---|---|
| S1 | 渐进揭示（F18） | 核心层 / 扩展层两阶段，**由孩子主动触发**，系统不自动推进（详见 §4） |
| S2 | 单屏信息密度上限 | 按 `ageRange` 分段取阈值（详见 §4.1），超限即在 DEV 环境 `console.warn` |
| S3 | 图文同步高亮 | 朗读时逐句高亮对应文本——**直接复用 `speakSequence({ onLine })`（`src/lib/speech.ts:410`），零新建** |
| S4 | 应用内"减少动效"开关 | 不依赖系统设置：家长中心新增 `reduceMotion`，与 `matchMedia` 取**逻辑或** |
| S5 | 色盲安全反馈配色 | 对 / 错反馈禁用"粉 vs 绿"；改为**蓝 vs 橙 + 形状 + 图标 + 文案**四重冗余（详见 §5.3） |
| S6 | 主操作放大 | 研究模式主 CTA（"开始探索""还有吗？""朗读"）用 `size="lg"` ≥64px；测验选项卡 ≥56px |
| S7 | 无时间压力 | 探索段与测验段**不显示倒计时**，不因超时判错（DDA 的 `>12s` 仅用于内部难度信号，**不得可视化为压力**） |
| S8 | 正向错误反馈 | 错误不用红色、不用 `--animate-shake`；改用轻微 `squishy` + 中性色 + "再想想"文案（对应 F19） |
| S9 | 状态可见 | AI 生成中 / 冷却中 / 离线降级均有可见状态（骨架屏 + 文案），**禁止空白等待** |
| S10 | 流式内容播报 | AI 流式讲解容器加 `aria-live="polite"`（读屏用户与朗读顺序一致） |
| S11 | 文案弹性 | 容器按 en-US 文案（普遍长 30–60%）预留伸缩，禁止定高文字容器造成截断 |
| S12 | 静音一致性 | `settings.sound = false` 时，朗读按钮呈"静音中，点此开启"可见态，而非点了没反应 |

### 2.3 Comprehensive —— 最优（P2）

> 定义：可为个体差异（低视力、听觉敏感、注意力障碍、阅读障碍倾向）做**个性化适配**，且家长有反馈通道。

| # | 条目 | 量化门槛 |
|---|---|---|
| C1 | 自定义字号 | 三档 **100% / 115% / 130%**（root font-size 缩放）；**前置条件见 §6 门控 G8（禁硬编码 px 字号）** |
| C2 | 语速调节 | 复用 `src/lib/tts/settings.ts` 的 `modulePresets`，新增模块 key `research`，家长可单独调速（0.6–1.0，基准 `BASE_RATE = 0.8`）——**零新建基础设施** |
| C3 | 高对比模式 | 正文 ≥ **7:1**（AAA）：`ink` on 纯白 = 10.36:1 ✅；同时提升卡片边界至 ≥4.5:1 |
| C4 | 认知负荷动态适配 | 依据"扩展层展开率 / 放弃率 / 重听次数"自动下调密度档（**不复用 DDA 的答题正确率信号**，避免把探索刷题化，对应 R6） |
| C5 | 家长可报告障碍 | 知识卡与探索页均有"这里看不清 / 读不懂"上报入口——**复用现有内容举报位**（R5 已规划的 `ContentStationPage` 报错位） |
| C6 | 音色可选 | 复用 `NEURAL_VOICES` 五音色（`src/lib/tts/settings.ts:38`），家长为孩子挑更易听懂的音色 |
| C7 | 单手 / 单侧可达 | 主操作集中在屏幕下 1/3 热区，横屏时不出现"必须双手才能触达"的布局 |
| C8 | 偏好跨档案隔离 | 可访问性偏好随多档案（`useProfilesStore`）隔离——两个孩子可有不同字号 / 语速 |

## 4. F18 认知负荷护栏 · 视觉规格

理论基座：Sweller 认知负荷（内在 / 外在 / 相关三分）+ Mayer 多媒体原则（连贯性、信号、空间邻近、时间邻近、分段、模态）。目标是**压外在负荷、留相关负荷**——把工作记忆预算花在"理解现象"，而不是"找哪里能点"。

### 4.1 单屏信息密度上限

| 指标 | 5–7 岁 | 8–10 岁 | 依据 / 备注 |
|---|:--:|:--:|---|
| 核心层概念数 | **1** | **≤2** | 工作记忆预算；【推断】→ B-1 |
| 核心层知识点条数 | **≤2** | **≤3** | 同上 |
| 单屏视觉元素数（可交互 + 图形，不含背景装饰） | **≤3** | **≤5** | Mayer 连贯性原则 |
| 单句字数 | **≤12** | **≤18** | 【推断】→ B-4 |
| 核心层可见总字数 | **≤40** | **≤80** | 【推断】→ B-4 |
| 扩展层最大层数 | **2** | **3** | 核心 + 扩展 ≤4 chunk |
| 同屏并发循环动画 | **≤1** | **≤1** | 测验段为 **0** |
| 背景装饰元素 | ≤3 且透明度 ≤20% | ≤5 且透明度 ≤25% | 装饰不得与内容争对比度 |

**执法方式**：阈值以常量写入 `researchTopics.ts`（F2），DEV 环境超限 `console.warn`（不阻断生产渲染），并进 §6 门控清单人工抽检。

### 4.2 图文比与版面

- **图占面积 55–70%**，文字 ≤30%，留白 ≥15%（核心层）。文字是"图的注解"，不是主体。
- **空间邻近**：说明文字与其对应图形的间距 ≤ **16px**，且**不允许跨屏滚动才能看到对应关系**（Mayer 空间邻近原则）。
- **时间邻近**：朗读某句时，对应视觉元素同步高亮/放大 ≤1.06 倍（Mayer 时间邻近 + 信号原则）。
- **冗余原则的正确处理**：Mayer 的"冗余原则"反对旁白 + **大段同义屏幕文字**并呈；但 5–10 岁处于识字期，短文本 + 同步高亮是**有益冗余**。因此规格是「**短句 + 逐句高亮**」，而非「长段落 + 全文朗读」——落地即 `speakSequence({ onLine })`。
- 阅读行长：中文 ≤ **16 字/行**，英文 ≤ **40 字符/行**。

### 4.3 分步揭示节奏

1. **进入 explore 阶段**：仅渲染核心层。扩展层入口是**单一显性按钮**（"还有吗？"），≥64px，位置固定不跳动。
2. **触发权在孩子**：系统**禁止**自动展开或定时展开（自动推进 = 强加外在负荷 + 剥夺自主感，违反 SDT）。
3. **最小间隔**：上一句 TTS 播完 + **400ms** 后才允许下一次揭示生效（防连点导致内容瀑布）。
4. **不预告总量**：不显示"还有 5 条"（会制造"任务量焦虑"）；用"还有一个小秘密"式的开放表达。
5. **可回收**：已展开的扩展层可折叠回去；折叠动画 ≤300ms。
6. **锚点稳定**：展开后核心层位置**不得位移**（内容在下方追加，不做整页重排）——避免低龄儿童丢失视觉锚点。

### 4.4 动画时长区间

| 类型 | 时长 | 现有资产映射（`index.css` @theme） | 备注 |
|---|---|---|---|
| 微反馈（点击 / 按压） | **150–300ms** | `--animate-squishy 0.3s` ✅ | 上限即 300ms |
| 元素入场 | **300–450ms** | `--animate-pop-in 0.42s` ✅ | 超 450ms 显迟滞 |
| 层间转场 / 揭示 | **250–400ms** | 新增，勿超 400ms | 缓动 `cubic-bezier(0.34,1.56,0.64,1)` 可保留弹性 |
| 折叠收起 | **≤300ms** | — | 收起应快于展开 |
| 奖励庆祝 | **≤1200ms 且可跳过** | `celebrate.ts` 现有 | 已读 `prefers-reduced-motion`，须沿用 |
| 循环 / 呼吸类 | 周期 ≥1.6s，幅度 ≤10px | `float 4s` / `twinkle 1.8s` / `bounce-soft 1.6s` | 探索段 ≤1 处，**测验段禁用** |
| 错误反馈 | 150–300ms，**禁 shake** | ~~`--animate-shake 0.45s`~~ | F19：抖动 + 红色对低龄是惩罚信号 |

**硬禁止**：>3Hz 闪烁；大面积（>25% 视口）明暗跳变；视差滚动；自动播放且无法暂停的动效。

## 5. 多模态无障碍

### 5.1 TTS 与视觉冗余矩阵

每条"知识单元"必须至少覆盖两个通道，且**可见文本为强制通道**：

| 通道 | 5–7 岁 | 8–10 岁 | 强制性 |
|---|---|---|---|
| 可见短文本 | 必选 | 必选 | **强制**（TTS 永不唯一） |
| 图形 / emoji / 插画 | 必选 | 建议 | 5–7 岁强制 |
| TTS 音频 | 默认开 | 默认可关，入口显眼 | 不得为唯一通道 |
| 交互反馈（形变 / 位移） | 建议 | 建议 | 不承载语义 |

**双向可读性**（本功能的核心可访问性命题）：
- **无语音也能懂**：关闭朗读后，仅凭可见文本 + 图形能完成理解与作答；所有 `speak()` 调用点须有同义可见内容。
- **无声画也能读**：视觉信息（如"红 + 黄 = 橙"的调色演示）必须有文字/朗读的等价描述，不能只靠动画演示传达结论。

### 5.2 无声模式（静音 / 不支持 TTS）

- `speak()` 在 `!synth` 时是**静默 resolve**（`speech.ts:249`）——对孩子等于"点了没反应"。研究模式朗读按钮**必须**自行判定并给可见回执：不支持 → "这台设备暂时不能朗读"；`settings.sound = false` → "静音中，点此开启"。
- 朗读进行中须有可见指示（复用 `useStore#ttsState`）+ 可见停止按钮 ≥44px。
- 朗读被高优先级打断时（`speech.ts` 优先级队列：praise 5 > quiz 4 > poem 3 > story 2 > general 1），**当前高亮句不得停留在错误位置**——打断即清高亮。

### 5.3 色盲 / 低视力配色约束

**实测结论（Viénot 1999 模拟，附录 A-3 附原始数据）**：

| 配色对 | 常态对比 | 红绿色盲（deutan）后 | 判定 |
|---|:--:|:--:|---|
| `green #5FD68B` vs `pink #FF6FA5` | 1.19:1 | **1.19:1** | ❌ 绝对禁止用于对/错区分 |
| `blue #4FC3F7` vs `yellow #FFC93C` | — | 1.63:1 | ⚠️ 色相可辨、亮度接近，须叠加形状 |
| `blue.deep #2196C9` vs `yellow.deep #D99C0E` | — | 2.18:1 | ⚠️ 同上，最优的一对但仍不够独立 |

**规格**：
1. **对 / 错反馈四重冗余**：颜色（蓝 = 对 / 橙 = 待改进）+ 图标（✓ / ○，≥24px 且带 1.5px 描边）+ 文案（"对啦" / "再想想"）+ 位置（固定槽位）。缺任一重即不合规。
2. 颜色**不得**编码类别信息（如"绿色主题 = 生物"），须同时有 emoji / 文字标签。
3. 低视力：正文最小 **16px**（儿童建议 **18px**）；图标最小 **24×24px**；一切浅糖果色（`candy-pink/blue/green/yellow` on 白，1.35–2.53:1）**只能做背景与装饰，禁止承载文字**。
4. 描边优先：卡片、图标、选项框依赖**描边 + 形状**区分，不依赖填充色差。
5. 不使用纯色相差异表达进度（进度条须同时有数字或分段刻度）。

## 附录 C · 技术风险提示（需与 engineering-lead 确认）

1. **`useSettingsStore` 缺 `merge`，新增可访问性字段对老用户会是 `undefined`**
   `src/store/useSettingsStore.ts` 的 `persist` 只配了 `name` 与 `storage`，未提供 `merge`。zustand 默认浅合并会用持久化的 `settings` **整体替换** `initialSettings`，因此新增 `reduceMotion` / `fontScale` / `highContrast` 后，**老用户读到 `undefined`**。
   → 对策二选一：(a) 给 `persist` 加 `merge`（对 `settings` 做 `{...initialSettings, ...persisted.settings}`，与 `tts/settings.ts` 的 `{...DEFAULT_SETTINGS, ...parsed}` 做法一致）；(b) 所有读取点强制 `?? 默认值`。**这与 GDD 的 C4（Progress 字段登记）是同类风险的另一半，建议一并纳入门禁 G19。**

2. **硬编码 px 字号会让 C1「自定义字号」失效**
   现状存在 `text-[15px]` 一类硬编码（如 `src/components/ui/Tabs.tsx:68`）。研究模式新组件必须用 rem 级 token，否则 root font-size 缩放不生效 → 门禁 G8。

3. **`prefers-reduced-motion` 目前只有 CSS 层降级**
   `index.css:303` 用 `!important` 压 animation/transition duration，但**无法约束 JS 驱动的动画**（motion 库、canvas、confetti）。`celebrate.ts:107` 已主动读 `matchMedia`，研究模式的任何 JS 动画须照此模式**显式判定**。

4. **`speak()` 不判 `settings.sound`**
   全局静音仅在 `announcePage` / `announceStep` 经 `voiceGuideEnabled()` 生效。研究模式朗读按钮须自行判定并给可见回执（S12 / G17），否则会出现"静音状态下仍朗读"或"点击无反馈"两种不一致体验。

5. **`AccessibleButton` 与 `CandyButton` 是两套体系**
   `AccessibleButton` 有完整 ARIA 但用的是 blue/gray 通用配色且 `sizes` 无 min-height（`px-3 py-1.5` 可能 <44px）；`CandyButton` 有尺寸与糖果风格但 ARIA 较弱。研究模式建议**以 `CandyButton` 为基础补 ARIA**，不要在同一页混用两套视觉语言——否则视觉一致性与可访问性会互相拖累。
