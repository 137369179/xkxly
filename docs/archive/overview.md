# 宝贝学习乐园 · 项目交付概览

> 一个面向 6 岁儿童的幼儿学习 Web 应用，**彩虹糖果**配色，PC 左侧栏 + 移动底部 Tab，按钮 ≥44px，进度用 localStorage 持久化，已部署上线并支持手机扫码访问。

## 技术栈
React 19 · Vite 7 · TypeScript(strict) · Tailwind CSS v4（`@theme`/`@utility`）· Zustand 5(persist) · motion(动画) · canvas-confetti · pinyin-pro · Web Speech API · Web Audio 合成音效

## 五大模块（全部完成）
1. **字母乐园** — 26 字母墙（点击朗读字母+单词）、大小写配对游戏（配对成功评 1–3 星）
2. **古诗花园** — **374 首**经典古诗，完整拼音标注，整首朗读逐句高亮，收藏 / 标记已读，搜索
3. **数字王国** — 0–100 数字墙（听读+点数可视化）、10/15/20 以内加减法、数物对应
4. **逻辑挑战** — 找规律 / 图形配对 / 排排序 / 综合，3 档难度
5. **闯关冒险** — 12 关地图（锁定/解锁），按关卡题型抽题，过关评星解锁下一关，徽章墙（24 枚）

首页仪表盘汇总星星、连续学习天数、各模块进度与下一个目标徽章。

## 关键架构
- `src/lib/questions.ts`：通用题目引擎，math/count/number/letter/logic(3 类)/poem 题型，被逻辑页与冒险页复用

- `src/data/poems.json`：374 首古诗语料（拼音由 `scripts/gen-poems.mjs` 生成，含 109 条破读纠正）

## v3 升级：古诗花园 → **古诗学院**（专业级研读系统）

把原来的「浏览 + 朗读 + 收藏」升级为一套可做**深度研究**的古诗学习系统，兼顾学术严谨与阅读美感。

### 1. 结构化研读（5 个标签页）
| 标签 | 内容 |
|---|---|
| **原文** | 逐字拼音 + 声调配色，注释/用典处带 `注`/`典` 上标，点击弹出释义浮条 |
| **注解** | 逐词注释、修辞标注（比喻/夸张/对偶/互文/白描…）、用典解析（出处 + 用意） |
| **格律** | 平仄网格、韵脚与韵辙、对仗联标注 |
| **语境** | 白话译文、作者小传、创作背景与本事 |
| **研读** | 我的批注、双栏对比研读、相似诗作推荐、进阶学习路径 |

### 2. 数据层
- `scripts/enrich-poems.mjs`：把 `poems.json` 富集为 `poems-deep.json`——自动判定**体裁**（按句数/字数分类为绝句/律诗/古体/乐府/词/曲/诗经楚辞）、抽取**意象**（51 类意象词典）、归并**主题**（45 类）、匹配**作者小传**（45 位重点诗人）、评定**难度**（1–5 级）。
- `scripts/add-canon.mjs`：补入 11 首必读经典（水调歌头、念奴娇·赤壁怀古、声声慢、登高、使至塞上、悯农…），补齐**词/曲/律诗/用典**样本。语料 374 → **385 首**。
- `src/data/poemDossiers.ts`：**54 篇必读名篇的手工深度作庭**（译文/注释/背景/用典/修辞/权威格律说明）。

### 3. 格律分析引擎 `src/lib/prosody.ts`
- **平仄**：现代声调判定 + **平水韵常用入声字表纠偏**（约 500 字），"急/白/不/独/客/出/直/国/竹" 等今读平声的入声字正确判为仄，并以琥珀色 `入` 单独标记。
- **押韵**：近体诗按「偶句必押、首句可入韵」**结构定位**；其余按现代**十三辙**宽韵归并，输出韵辙名（怀来辙/言前辙…）。韵脚位置与主韵不一致时标 `*` 并提示**古今音变**（如《登高》"回/杯" 今读 -ei，中古与 "哀/来/台" 同属十灰）。
- **对仗**：律诗自动标注颔联/颈联，精选名篇可由作庭手工覆盖说明。

### 4. 多维检索
朝代（10）× 体裁（11）× 主题（45）× 意象（51）四个维度可**多选交集**筛选，叠加关键词搜索与「仅看收藏 / 仅看精讲」。

### 5. 智能推荐
- **相似诗作**：主题×2 + 意象×1 + 同作者+3 + 同朝代+1 的相似度打分排序。
- **进阶路径**：同体裁、难度 ≥ 当前的下一档作品，形成由浅入深的研读链。
- **对比研读**：任选两首左右双栏对照，逐句比对。

### 6. 用户标注
批注写入 `progress.poemNotes`，随 Zustand persist 落 localStorage，`merge` 深合并保证老用户数据不丢。

### 5. 关键学术修正（避免误判名家）
- **孤平须加「相邻韵脚」例外**：标准尾式 `仄仄仄平平` 仅余一平但紧邻韵脚属常格，非孤平；真孤平为 `仄平仄仄平` 类。初版误判《登鹳雀楼》「更上一层楼」，已修。
- **近体韵部以偶句为准**：仄收首句尾字不计入主韵；平收首句一律视为入韵（宽容古今音变，如「斜」xié 与「家/花」平水韵同麻韵）。初版误判《山行》《池上》《风》《回乡偶书》出律，已修。
- **古绝不判失对/失粘**：唐人古绝句自由成趣，失对/失粘改由 UI 以「拗」可视化。
- **入声表补全**：「撷/缬/颉/荚」等补入 `RUSHENG`。

### 6. 录音对照升级为真实声波分析（需求 #5 深化）
- 新增 `src/lib/audioCompare.ts`：纯函数 `analyzeEnvelope` 用**静音间隙切分**还原逐字真实时长，与预期「平长仄短」谱做皮尔逊相关性 → `fit`（节奏契合度），另算 `timeFit`（真实总时长契合）；浏览器侧 `decodeToAnalysis` 用 `AudioContext` 解码录音。
- `poemTrain.tsx` 的 `ChantBar` 接入：每句录音解码后，逐字渲染「实际声波条」（平蓝/仄粉/入橙，宽度=真实时长）叠在期望节奏条下；评分卡片显示**节奏 / 平仄 / 时长**三项 + 针对性点评。连续无停顿朗读无法切分时诚实降级为中性分并提示「句内稍作停顿」。
- 合成测试验证：好读者 `fit=100` / 单调 `fit=50` / 连续朗读 `segmented=false→中性 50`。`tsc` 0 错误，`npm run build` 通过，已上线。
- 经验：**依赖「期望」反推的评分类指标会假性 100%**，必须用真实观测推导。
