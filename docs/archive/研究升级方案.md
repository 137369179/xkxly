# 宝贝学习乐园 · 产品研究与 v2 升级方案

> 文档目标：基于对主流幼儿学习产品（洪恩、帮帮识字等）的架构与产品模型研究，明确「现有系统」与「行业标杆」之间的差距，并据此落地 v2 的四项核心升级，提升专业性与学习效果。
>
> 适用对象：6 岁儿童 · 幼儿启蒙（字母 / 古诗 / 数字 / 逻辑）
> 配套产物：`dist/`（已部署）、`扫码访问.png`（扫码入口）

---

## 一、竞品研究：主流产品的核心模型

### 1.1 洪恩识字 / 洪恩系列（玩中学的标杆）

**核心交互闭环（5 步法）：**
`玩（情境动画引入）→ 认（字卡 + 标准音）→ 练（小游戏巩固）→ 写（笔画描红）→ 说（朗读评测）`

**产品模型要点：**
- **大地图闯关**：把所有内容切成「关卡」，孩子在一张卡通地图上逐关解锁，进度可视化、目标感强。
- **情境化动画**：每个字都裹在一个生活小故事里，先激发兴趣再教认。
- **强反馈与即时奖励**：每一步都有音效、星星、动画庆祝，错也不会被批评。
- **短板**：答错后通常只说「再试试」，缺乏**错因解释**；复习节奏偏固定，缺少基于遗忘曲线的个性化。

### 1.2 帮帮识字 / 悟空识字（结构化进阶的代表）

**核心交互闭环（5 步法）：**
`学（动画讲解）→ 认（字卡）→ 读（跟读评测）→ 练（游戏）→ 写（描红）+ AI 语音评测`

**产品模型要点：**
- **三级字表阶梯**：按常用度拆成 1300 字左右的 3 个难度梯队，循序渐进。
- **遗忘曲线复习**：根据艾宾浩斯安排复习日，到点提醒回看。
- **每日打卡 + 家长报告**：用连续打卡培养习惯，用周报向家长交付「学了什么、掌握多少」。
- **短板**：同样**不解释为什么错**；家长报告偏统计，缺少「薄弱点 → 针对性补救」的闭环。

### 1.3 横向对比（含 Khan Academy Kids / ABCmouse 等国际产品）

| 维度 | 洪恩 | 帮帮识字 | 国际产品(Khan/ABCmouse) | 我们的 v2 |
|---|---|---|---|---|
| 学习闭环 | 玩认练写说 | 学认读练写 | 看练测闯 | **玩认练写说 + 错因解释** |
| 复习机制 | 固定节奏 | 遗忘曲线 | 自适应间隔 | **自适应间隔重复(SRS)** |
| 家长视角 | 简单报告 | 周报 | 进度仪表盘 | **掌握度热力图 + 薄弱 TOP + 时长护眼** |
| 激励方式 | 星星/勋章 | 星星/解锁 | 装饰/宠物 | **贴纸收集册（可消费）** |
| 错因反馈 | ❌ | ❌ | 部分 | ✅ **为什么错了** |
| 每日路径 | 自由探索 | 固定课程 | 推荐路径 | **每日课程包（稳定不漂移）** |

**关键洞察**：行业内「闭环 + 大地图 + 家长报告」已成标配，但**「答错后给错因解释」是普遍空白**——这正是我们与洪恩/帮帮拉开专业差距的差异化突破口。

## 二、差距分析：现有系统 → 行业标杆

研究前（v1）我们已具备：5 大模块、题目引擎、闯关地图、徽章墙、Web Speech 朗读。对照标杆，差距集中在四点：

| # | 差距 | 表现 | 影响 |
|---|---|---|---|
| G1 | **无学习路径** | 首页是模块菜单，孩子「今天该学什么」靠自己选 | 目标感弱、易跳过基础 |
| G2 | **无科学复习** | 答对答错只加/减星，掌握度不沉淀 | 学了就忘、错题不复现 |
| G3 | **交互缺标准闭环** | 字母/数字模块各自为政，无统一「认-练-写-说」 | 体验不一致、专业性不足 |
| G4 | **家长端缺失** | 无报告、无限时、无护眼提醒 | 家长无法参与、易用眼过度 |

## 三、v2 升级方案（四维度）

### 3.1 功能结构：从「模块菜单」到「学习路径中枢」

- **新增「今日课程」页**（首页一级入口）：每天自动生成一份约 12 分钟的课程包——`暖身复习 → 新字母 → 新数字 → 新古诗 → 综合测验`，引导孩子「今天该学什么」。
- **信息架构重排**：底部 Tab 收敛为 6 个核心（首页 / 今日 / 字母 / 数字 / 闯关 / 奖励），古诗、逻辑、家长收进导航；避免幼儿选项过载。
- **课程包「当日稳定」**：同一天内不会因刷新而重排，保证学习连贯（基于 `dateKey` 记忆当天进度）。

### 3.2 学习路径：间隔重复 + 五步闭环

- **SRS 掌握度引擎**（`src/lib/srs.ts`）：6 级掌握度 [0–5]、固定复习间隔 [0,1,2,4,7,15] 天；答错只降 1 级并触发 10 分钟重学（**不清零**，保护信心）。
- **五步学习闭环**（`LearnFlow` 通用壳）：
  - 字母：`玩 / 认 / 练 / 写 / 说`
  - 数字：`认 / 数 / 写 / 说`
  - 古诗：`听 / 读 / 填 / 背`
- **笔顺描红**（`TraceCanvas`）：Canvas 覆盖网格判定描红轨迹，无需逐笔数据，体验顺滑。
- **自适应难度**：根据历史正确率动态升降难度（`adaptiveDifficulty`）。
- **错题本加权重出**（`makeSpacedDrill`）：约 35% 概率优先从「到期复习 + 错题本」抽同分类题，针对性补弱。

### 3.3 用户交互：一致性 + 即时反馈

- **统一组件**：`LearnFlow` / `FlowStep` 被字母、数字、古诗、今日课程共用，消除体验割裂。
- **正向反馈体系**：`celebrateSmall` / `celebrateBig` 礼花 + `BigPraise` 语音表扬，错不批评、只给「再试一次」引导。
- **自适应复习注入**：四个练习场景（数学/数数/逻辑/冒险）统一接入 `makeSpacedDrill` + `RoundRunner.onAnswered`，逐题回写掌握度。

### 3.4 内容呈现：错因解释（差异化核心）

- **每道题携带 `why` 字段**：答错时弹出「为什么错了」的儿童化讲解（如「b 和 d 像个镜子，b 先写竖再写右半圆」），把标杆产品的空白补上。
- **家长中心**（`ParentPage`）：4 位 PIN 门禁、每日时长上限、护眼提醒、掌握度热力图、薄弱技能 TOP 榜、今日学习日志。
- **奖励中心**（`RewardsPage`）：星星钱包 → 贴纸收集册（可消费兑换）、徽章墙、错题本一键清空。把「被动勋章」升级为「主动收集经济」，提升内驱力。

## 六、后续可迭代方向（非本次范围）

1. **错因讲解音频化**：当前 `why` 为文本，可接入 TTS 朗读，进一步降低识字门槛。
2. **家长周报导出**：PDF/图片分享，方便转发给家人。
3. **多娃档案**：一套应用支持多个孩子的独立进度（PIN 区分）。
4. **内容扩充**：字母/数字之外的「形状/颜色/自然」主题关卡。
