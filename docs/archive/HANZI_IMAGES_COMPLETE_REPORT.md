## 🔧 技术实现细节

### 1. Canvas 程序化生成器
**文件**: `src/lib/hanziImgGen.ts` (1229 行)

支持六书类型：
- **象形字** (pictographic): 画事物本身
- **指事字** (ideographic): 示意图解 + 箭头
- **会意字** (compound-ideographic): 场景拼合
- **形声字** (pictophonetic): 场景图 + 形旁高亮

### 2. IndexedDB 缓存层
**文件**: `src/lib/hanziImgDb.ts` (112 行)

两级缓存：
- L1: 内存 Map（毫秒级读取）
- L2: IndexedDB（持久化，~50MB 配额）

### 3. AI 图像生成服务
**文件**: `src/lib/hanziImageAI.ts` (177 行)

预留 StepFun FLUX API 接口：
```typescript
const response = await fetch('/api/hanzi/image/:char', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ char, liushu, origin }),
});
```

### 4. 演变动画组件
**文件**: `src/components/hanzi/EvolutionAnimation.tsx` (482 行)

5 阶段动画：
1. 原始图画 → 可爱插画风格
2. 简笔画 → 几何抽象
3. 甲骨文 → 龟甲刻痕
4. 金文 → 青铜器规范
5. 楷书 → 现代汉字

### 5. 组装动画组件
**文件**: `src/components/hanzi/AssemblyAnimation.tsx` (234 行)

4 阶段动画：
1. 准备 → "开始动画"按钮
2. 飞入 → 部件从四周飞向中心
3. 组合 → 部件高亮排列
4. 完成 → 汉字缩放弹跳 + 粒子庆祝 ✨⭐🌟💫🎉🎊

### 6. 配图卡片组件
**文件**: `src/components/hanzi/HanziImageCard.tsx` (340 行)

三层渲染策略：
1. IndexedDB 缓存命中 → 直接显示
2. AI 生成 → 写入缓存后显示
3. Canvas 降级 → 兜底显示

## 🚀 使用方法

### 基础用法
```tsx
import { HanziImageCard } from '@/components/hanzi/HanziImageCard';

<HanziImageCard
  char="日"
  pinyin="rì"
  liushu="pictographic"
  origin="古人看见圆圆的太阳"
  size="medium"
/>
```

### 演变动画
```tsx
<EvolutionAnimation
  char="日"
  pinyin="rì"
  autoPlay={false}
  speed={2500}
/>
```

### 组装动画
```tsx
<AssemblyAnimation
  char="明"
  pinyin="míng"
/>
```
