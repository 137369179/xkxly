## 🔧 技术实现

### 三层架构

```
┌─────────────────────────────────────────────────────────────┐
│                    HanziImageCard 组件                      │
│                                                             │
│   ┌─────────────┐    ┌─────────────┐    ┌─────────────┐   │
│   │  IndexedDB  │───→│   Canvas    │───→│   AI 生成   │   │
│   │   缓存命中   │    │  程序化绘制  │    │  (备用)     │   │
│   └─────────────┘    └─────────────┘    └─────────────┘   │
│        ↓                   ↓                  ↓            │
│     直接显示           fallback 兜底        异步写入缓存     │
│     (毫秒级)           (~50ms/字)         (可选升级)       │
└─────────────────────────────────────────────────────────────┘
```

| `src/lib/hanziImgGen.ts` | 1229 | Canvas 程序化生成器 |

## 🚀 使用方法

### 基础用法
```tsx
import { HanziImageCard } from '@/components/hanzi/HanziImageCard';

<HanziImageCard
  char="日"
  pinyin="rì"
  liushu="pictographic"
  origin="古人看见圆圆的太阳"
  size="medium"
/>
```

### 演变动画
```tsx
<EvolutionAnimation
  char="日"
  pinyin="rì"
  autoPlay={false}
  speed={2500}
/>
```

### 组装动画
```tsx
<AssemblyAnimation
  char="明"
  pinyin="míng"
/>
```
