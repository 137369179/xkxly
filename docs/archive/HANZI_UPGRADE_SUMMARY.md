## 🎨 视觉风格规范

### 儿童插画风格约束
| 元素 | 规范 |
|------|------|
| 配色 | 低饱和度糖果色（粉 #FFB6C1、薄荷绿 #98FB98、淡黄 #FFFACD） |
| 形状 | 圆角、粗描边（3-5px）、简约几何 |
| 表情 | 所有物体都有可爱笑脸（大眼 + 腮红 + 微笑） |
| 背景 | 纯色或渐变，无复杂纹理 |
| 尺寸 | 统一 256×256 或 512×512 |

### 六书类型对应风格
| 类型 | 中文名称 | 风格特点 |
|------|----------|----------|
| pictographic | 象形字 | 画事物本身，写实简化，带笑脸 |
| ideographic | 指事字 | 示意图解，标注说明，箭头指示 |
| compound-ideographic | 会意字 | 场景拼合，左右/上下结构对比 |
| pictophonetic | 形声字 | 分屏展示，形旁表义 + 声旁表音 |
