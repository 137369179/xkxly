# T-3.2 SRS 复习中心 · 模块设计文档

> **所属**：`docs/儿童成语学习功能开发任务清单_2026-08-20.md` — T-3.2 / T-3.5
> **版本 / 日期**：v0.1-draft / 2026-08-20
> **目标**：为 6–12 岁儿童提供按遗忘曲线安排的成语复习，采用"**先回忆，后揭示**"的主动提取方式，复习结果回写掌握度数据，避免集中式无效重背。
> **验收参照**：T-3.1 / T-3.2 / T-3.5 的验收标准。

---

## 1. 目标与原则
- **复用**：不新建第二套待办/进度体系，直接落在现有 `progress.mastery` 与 `srs` 引擎上。
- **低挫败**：答错温和降级（`srs.review` 已内置，不清零），每日复习量设上限，超出自然顺延。
- **主动提取**：先呈现记忆线索（含义/词面之一），儿童先在脑中回忆，再"揭晓"答案按钮对比，最后自评"记得 / 忘了"写回。
- **难度感知**：写回时透传 `difficulty = idiom.level`，让高难度答对加速晋级、低难度答错重点回退（`review` 难度感知逻辑）。

## 2. 数据模型（复用既有）
- 知识点 id：新增 `srs.SKILL.idiom(id) => 'idiom:<id>'`，与 `interview`/`bath` 同一套说明。
- 掌握项：`progress.mastery[skill] = { lv, due, ok, ng, last }`；`due <= now` 即到期可复习。
- 复习完成回写：`useStore().practice(skill, correct, star, difficulty)`（内部已走 `srs.review`，并维护 `ok/ng`）。
- 无侵入：不新增持久化表；`idiom` 与其它学科共享同一 `mastery` 命名空间。

## 3. 逻辑单元（src/modules/idioms/idiomSrs.ts —— 建议纯函数）
| 函数 | 签名 | 说明 |
|---|---|---|
| `selectDueIdioms(mastery, now, limit?)` | `(mastery, now, limit=MAX_DAILY) => string[]` | 过滤 `idiom:` 前缀且 `due<=now`，按 `due` 升序取前 N，返回 skill id |
| `dueIdiomCount(mastery, now)` | => number | 今日待复习总数 |
| （组件钩子）`useDueIdiomSkills()` | => string[] | 细粒度订阅：仅当 `idiom:` 类 mastery 变化时更新（避免整块 mastery 抖动） |

> 建议 `MAX_DAILY = 10`（与儿童版 srs 每日上限一致）。

## 4. 组件设计（src/modules/idioms/IdiomReviewCenter.tsx）
```
IdiomReviewCenter
 ├ 头部：今日待复习 N
 ├ dueCount=0 → 空态鼓励（🎉 今天都复习完啦）
 ├ dueCount>0 → 卡片流
 │   每张卡片（复用 IdiomArt + CategoryBadge）：
 │   ├ 阶段A「回忆」：展示含义（或 emoji显图+词面反置）→ 提示"先在心里想一想"
 │   ├ 按钮「揭晓答案」→ 阶段B：呈现 深伪印 -> 揭晓 成语 + 图 + 拼音 + 释义回顾
 │   └ 自评按钮：✅「我记住了」 / ❌「又忘了」
 │       → 调用 practice(skill, 记住?true:false, 0, idiom.level)
 └ 全部完成后：完成动效 + 返回入口按钮
```

### 4.1 学习状态与写回
- 用 `useBlock`/局部 index 维护"当前卡片"与"阶段"（回忆 / 揭示 / 自评）；
- 每张卡自评一次即写回一次 `practice`，随后 `next()`；
- `star=0`：复习默认不计星星（避免刷星）；奖励专心通过"每日复习完成"单独给予（可选）。

## 5. 验收对照
| 验收项（来自任务清单） | 达成方式 |
|---|---|
| 复习列表按 srs 计算且可完成 | `selectDueIdioms` 由 `due` 驱动；完成后 `practice` 更新 `due` |
| 完成后状态回写 | `practice` 写回 `progress.mastery`；刷新后 `dueCount` 减少 |
| 空任务时优雅提示 | `dueCount=0` 空态 |
| 主动提取（先回忆后揭示） | 阶段A→B 顺序 |
| 不反弹其它测验 | 新组件独立挂载，不影响 `QuizSessionRunner` |

## 6. 无障碍与安全
- 复习/自评按钮提供 `aria-label`；
- 热区 ≥44px；"揭晓"前提示语清晰；
- 无新增外部链接；插画走本地资源（`IdiomArt` 已处理兜底）。

## 7. 开放问题 / 后续

- 每日复习完成奖励：是否给星星/徽章，待产品确认。
- 是否把"易混辨析"并入复习中心（对 T-3.4 友好），留待 P2。
