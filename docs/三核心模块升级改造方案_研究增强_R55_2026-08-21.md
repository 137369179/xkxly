## 二、竞品研究增强（洪恩识字 / 宝宝巴士 / 帮帮识字 + 英语数学同类）

### 2.1 洪恩识字（识字赛道标杆）
- **五步学习闭环**：玩 → 认 → 练 → 写 → 测，多感官参与。
- **游戏化玩法**：汉字竞技大闯关、难字歼灭、每周挑战；星星/徽章激励。
- **护眼**：内置护眼模式与休息提醒。

### 2.2 宝宝巴士汉字（系统性与角色陪伴）
- **五步识字闭环**：认、学、读、写、练 + 科学复习（一字一练 / 一课一练 / 三课一测；AI 智能复习 + 生活化复习如超市/公园）。
- **分龄分层**：3-4 岁象形识字 → 5-6 岁形近字/偏旁分类 → 7-8 岁衔接小学字词短句。
- **角色陪伴**：熊猫奇奇/妙妙全程引导，降低操作门槛。
- **成长可视化**：称号系统（如「阅读小达人」）、知识图谱、家长成长报告。
- **闯关奖励**：贴纸、动画短片等学习福利。

### 2.3 帮帮识字（激励与宽容度设计）
- **七步识记**：学、认、读、练、写、测、复习，配套 130 本原创绘本。
- **每日推荐**：智能推送 5 新字 + 3 复习字，保持适量输入不超负荷。
- **掌握度可视化**：学习报告以「花朵」图标表示掌握度，每学会 5 字解锁 1 朵花，激发收集欲。
- **护眼**：每 15 分钟弹休息提醒，过滤蓝光。
- **书写宽容度**：笔画识别偏离度 ≤20% 仍视为正确，减少挫败感。
- **成就激励 + 虚拟商城**：成就系统 + 虚拟商城兑换，内驱力十足。
- **L1-L4 科学分阶**：300 字启蒙 → 1900 字进阶。

### 2.4 英语 / 数学同类（叽里呱啦 · ABC Reading · 宝宝巴士 ABC/数学）
- **英语**：场景主题教学（75+ 主题）、AI 跟读评测纠音、分级绘本解锁、勋章激励。
- **数学**：知识点闯关、生活场景数学（配料配比/定价）、逻辑与空间训练。

### 2.5 提炼可复用机制（映射到既有基础设施）
1. **多步学习闭环**（认-学-读-写-练-测）→ 固化到 `HanziLearn`/`WordLearn` 流程。
2. **分龄分层开放** → 难度档位 + 年龄段徽标（逻辑已落地，识字/数学可复用）。
3. **角色陪伴** → 复用 `companion`/`pet` 模块陪伴引导。
4. **掌握度可视化（花朵/星星）** → 复用全局 stars + 成就墙 + 进度花。
5. **书写宽容度 ≤20%** → 描红/书写判定引入容错阈值。
6. **护眼休息提醒** → 新增全局护眼模块（待确认增强）。
7. **虚拟商城/称号** → 复用 `rewards` 模块 + 称号系统。

## 四、具体实施内容（按模块，严格限定现有模块内）

### 4.1 识字 `hanzi`（对标洪恩五步 + 宝宝巴士分龄 + 帮帮宽容度）
- 固化 **认-学-读-写-练-测** 六步闭环到 `HanziLearn` / `WordBuilder`。
- 「汉字竞技大闯关」：复用 `StreakBar` 连对闯关条做阶段性 Boss 关（洪恩式难字歼灭）。
- **描红宽容度**：笔画判定引入 ≤20% 偏离容错（帮帮式），降低挫败。
- **象形探秘**接入分龄徽标（3-4 象形 → 5-6 偏旁 → 7-8 衔接）。
- 每掌握 5 字点亮 1 朵「进度花」（帮帮式掌握度可视化）。

### 4.2 英语 `letters` + `words`（对标叽里呱啦/ABC Reading/宝宝巴士 ABC）
- **字母冒险闯关**：`LetterOrder`/`MatchGame`/`LetterPopGame` 串联成主题关卡，连对解锁下关。
- **单词跟读评测**：接入 AI 语音评测（帮帮式纠音）给出发音反馈；未接入时优雅降级到 Web Speech TTS。
- **场景主题 + 绘本解锁**：单词关通关解锁对应分级绘本（复用 `storybook`）。
- **连对勋章**：3 连对触发 `combo` 表扬场景（已落地 `praise.ts` word/letter 场景）。

### 4.3 数学 `numbers`（对标宝宝巴士数学 + 速算排行）
- **三档难度闯关问答**（R54 范式）：`MathLadder`/`SpeedMath`/`WordProblems` 接入 `StreakBar` 连对里程碑。
- **生活场景数学**：计数/应用题引入超市、厨房等生活情境（宝宝巴士式跨学科融合）。
- **速算排行榜**：`SpeedRankings` 持久化 + 好友榜（复用现有）。
- **逻辑大师徽章链路**：数学正确率累计解锁 `number-*` 系列徽章（扩展 `badges.ts`）。

### 4.4 统一横向能力
- **全局星星货币** + **成就墙**（`achievement`）+ **奖励解锁**（`rewards`）。
- **家长报告**：知识图谱 + 成长报告深链（`parent`/`growth`），含连对记录与掌握度花。
- **护眼提醒**（待确认增强）：全局 15 分钟休息弹窗 + 蓝光过滤。
