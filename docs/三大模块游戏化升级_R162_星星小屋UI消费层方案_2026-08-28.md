### 2.2 理论侧（直接约束本轮设计）

**① 目标梯度效应（Goal-Gradient Effect）**
Kivetz / Urminsky / Zheng (2006) 咖啡卡实验：集 10 送 1 的**空白卡**完成率 19%，而集 12 但**已预盖 2 格**的卡完成率 34%——实际都要再盖 10 格，差别只在「已经开始」的视觉暗示。
→ **本轮设计**：星星银行的兑换进度条对**第一档目标**给予视觉预填充感，并显示「还差 N 颗」而非「已完成 X 颗」。

**② 奖励后重置现象（Post-Reward Reset）**
Coglode 综述明确指出：目标达成后动机**会瞬间跌回基线**，即使下一个奖励已在视野内——「这是你最可能失去用户的时刻」。
→ **本轮设计**：解锁成功的瞬间，`nextRewardGoal` 立即重算并**同屏呈现下一个目标**，用「新目标已就位」填平动机断崖，而不是先弹庆祝再回到空列表。

**③ 蔡格尼克效应 / 收集册完成度**
人天生厌恶未完成的序列。
→ **本轮设计**：收集册按档位展示 `ownedCount / total`，未收集的格子以虚线占位（不是隐藏），让「缺口」本身成为牵引力。

### 2.3 反方证据（沿用并加固既有护栏）

| 证据 | 对本轮的约束 |
|------|--------------|
| Deci / Koestner / Ryan 元分析：过度理由效应，奖励撤除后内驱低于初始 | R160 `rewardStage` 折算（1.0→0.85→0.7→0.6）继续生效 |
| Lepper / Greene / Nisbett (1973)：对本来就喜欢的活动给奖励，撤除后做得更少 | 「奖励是脚手架，不是发动机」 |
| ScreenWise 2026《Dopamine-Learning Trap》：可变比率强化 = 斯金纳箱核心 | 因此概率必须**公示到两位小数**、保底次数必须**可见**——透明即反操控 |
| MDPI SLR：competition / badges 对部分儿童造成压力 | 全站零排行、零对战、零惩罚 |

**本轮新增护栏**：扭蛋机主界面上，概率公示与保底剩余是**常驻可见**的一级信息，而非藏在「规则说明」折叠层里。把合规义务直接做成反操控手段。

### 4.3 关键设计决策

| 决策 | 理由 |
|------|------|
| 组件做成**受控**（数据 + 回调入参，不内部调 hook） | 单测可注入假数据，不依赖 localStorage；同时让三核心未来接入时只需传值 |
| 余额不足文案复用 `redeem()` 返回值 | 目标型文案（「再集 N 颗星就能解锁 X 啦」）只有一份实现，UI 绝不重写第二份 |
| 概率数字**只从 `capsuleOdds()` 取** | UI 里不出现任何硬编码概率，从根上杜绝「公示值与实际算法漂移」 |
| 动效走 `reducedMotion` 入参 + `@media prefers-reduced-motion` 双保险 | 家长护眼场景可关闭 |
| 无 `any` / `!` / `as` / `console` | 与 R159–R161 一致的零逃逸断言 |
