## 四、2026.8 数学游戏化专项研究（本轮新检索，针对最薄弱数字模块）

### 4.1 核心结论（来源：Prodigy 2026 家长指南 / equations.live / starsnet / commercialtoolry）
1. **「数学即机制，而非打断」**：有效数学游戏把算题嵌入冒险（答题=施法/击退怪兽/解锁区域），数学是玩法本身，不是「游戏皮下的练习册」。→ 直接指导 MathQuiz RPG 深化（增强①）。
2. **自适应 flow 状态**：难度随真实表现动态调整（非按年龄/年级固定），超前者受挑战、落后者获支持；维持「心流」免于无聊或挫败。→ 强化 `useAdaptive` 在数字模块的渗透（增强②）。
3. **变比率奖励 + 信息性反馈 > 空洞积分**：奖励应奖励「学习行为」而非「完成动作」；用可变比率奖励与「解释为什么错」的反馈，避免 over-rewarding 削弱内在动机。→ 印证 E（反馈质量>奖励）+ 我方「掌握度>积分 / 2胜即停」设计（增强③）。
4. **间隔重复 + 交错练习**：游戏化设计易嵌入 spaced repetition 与 interleaving，强化提取路径、降低遗忘。→ 印证 C（错字本 SRS）（增强⑤）。
5. **家长仪表盘**：进度/弱项/每日目标可视化，COPPA/FERPA 合规。→ 印证 G4 家长学习报告（增强⑤）。
6. **每循环单学习目标**：避免目标过多稀释练习、增加认知负荷。→ MathQuiz 收敛为单一清晰目标（如「10 以内加减」一关一目标）。

### 4.2 与既有 Core Loop v2 的关系
上述 6 条 100% 收敛于既有 Core Loop v2（核心动作即所练技能 / 自适应 / 反馈质量>奖励 / 掌握度>分数 / 2胜即停 / 家长报告），**未产生颠覆性需求**，仅将数字模块的具体落地路径讲清、讲细。
