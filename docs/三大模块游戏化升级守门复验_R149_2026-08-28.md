## 本轮定位
在 R144–R148 已为汉字 / 词语 / 数字三核心建立 `@/game` 游戏化基础设施（成就地图 StarQuest、连击 ComboMeter、即时反馈 GentleFeedback、护眼 RestReminder、自适应难度）的基础上，本次专门补齐**最弱一环**：`numbers/MathQuiz` 此前仅挂载了 `RestReminder`，缺少 `ComboMeter`（实时连击·任务#1）与 `GentleFeedback`（即时反馈·任务#3）。本轮将其与其余两个核心拉齐到同一游戏化标准。

## 改造目标与实施内容（纯增量·零学习逻辑改动）
- **挂载 `ComboMeter`**：在 `MathQuiz` 内新增 `combo` 状态，由既有 `onAnswered(q, c) => recordMath(c, q.skill)` 回调派生（答对 +1、答错归零），驱动 `@/game` 实时连击能量条。满足任务#1 积分/连击激励。
- **挂载 `GentleFeedback`**：由同一 `onAnswered` 回调判定正误并组装 `correct`/`msg`，复用既有 `praiseByScene('math')` / `encourageByScene('math')` 文案。满足任务#3 即时反馈（正确积极强化、错误温和引导）。
- **不动** `recordMath`、出题逻辑、RoundRunner、任何既有学习算法；仅新增 2 个 import + 1 个 `combo` 状态 + 2 行挂载。改动量 `MathQuiz.tsx` `+29 / -4`。
- **新增接线测试** `MathQuiz.gamification.test.tsx`：断言 ComboMeter（`aria-label="当前连击 0"`）与成就层（`MathStarQuest`→「数学探险地图」）已接入数字练习闭环；建模于已验证的 `HanziQuizGame.gamification.test.tsx` 范式，最小 mock（motion/sfx/praise 真实、speak 覆盖）。

## 研究佐证（2026 文献，用于升级方案而非改代码）
- **NeurekaNUM**（U. Barcelona, 2026）：15–20 分钟短会话 + 自适应难度 → 数学成绩显著优于对照组；强调让孩子「处于能力边缘——有挑战但不至于触发杏仁核 shutdown」。**直接支撑** GentleFeedback（非惩罚式）与 RestReminder 15 分钟节奏。
