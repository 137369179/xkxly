## 五、三核心接入方式（用户合并 WIP 后一键采用）

```tsx
// 汉字核心 HanziLearn.tsx（用户 WIP 合并后，仅加 1 行 import + 1 行 hook）
import { useGamification, GentleFeedback, AchievementWall, LevelProgress } from '@/game';

function HanziLearn() {
  const g = useGamification({ module: 'hanzi', skill: currentChar.id });
  // 答对：g.handleAnswer(true) → 自动评分/连胜/成就/庆祝
  // 答错：g.handleAnswer(false) → 触发 GentleFeedback 温和引导
  return (
    <>
      <LevelProgress progress={g.progress} />
      <GentleFeedback result={g.lastResult} />
      <AchievementWall achievements={g.unlockedAchievements} />
    </>
  );
}
```

> 接入点为**纯增量**：不修改三核心既有逻辑，仅 import + 调用，满足「优先重构优化既有逻辑、严格限定改造范围」且零回归风险（引擎经 19 用例验证）。
